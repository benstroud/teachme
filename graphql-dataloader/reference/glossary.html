DataLoader Glossary

Every term in this course, in one place. Return here when a lesson uses a word you do not fully own.

The problem

N+1 problem
A query pattern where resolving an operation issues one query for a list and then one extra query per item — N+1 queries total for one request. It arises from per-item resolver execution.2
resolver execution
The way GraphQL resolves a nested selection: a parent field resolver returns objects, then each object's children are resolved by (potentially) their own resolver called once per item.
round-trip
One request/response exchange with a data source (database or service). Each per-item resolver call tends to produce one round-trip.

DataLoader

DataLoader
A generic utility for the data-fetching layer that provides batching and caching of loads over a data source. `npm install dataloader`.1
batching
DataLoader's primary feature: individual `load()` calls made within a single frame (one tick of the event loop) are coalesced into one call of the batch function with all requested keys.1
memoization cache
The in-memory cache a DataLoader instance keeps: once a key resolves it is cached, so loading the same object twice in one request avoids a second fetch.1
batchLoadFn (batch function)
The function passed to `new DataLoader(batchLoadFn)`. It receives an Array of keys and must return a Promise for an Array of values, aligned by index with the keys.1
index alignment
The hard rule that the returned Array from a batch function is the same length as the keys Array and each value sits at the same index as the key it answers.1
load(key)
Requests a single value for a key; returns a Promise. Called many times, these are what get batched.1
loadMany(keys)
Requests several keys at once; useful with `Promise.all` and resolves to an Array of results.1
prime(key, value)
Seeds a key/value pair into the cache so a later `load` for that key does not hit the batch function.1
cacheKeyFn
An optional function that transforms a key into the cache key, letting you normalize or stringify composite keys.1
maxBatchSize
An option that breaks a large batch into groups of at most this many keys, so a huge query does not produce an oversized single batch.1
per-request instance
The pattern of creating a fresh DataLoader per request (not globally), so its memoization cache cannot leak one user's data into another's.1

Apollo Server integration

contextValue
The per-request object Apollo builds (via the `context` function) and passes to every resolver for that request; the natural home for per-request loaders.3
context function
The per-request function in `startStandaloneServer` (or an integration) whose return value becomes `contextValue`.3
data source class
An encapsulating class for fetching from one source, exposing methods resolvers call; Apollo recommends using DataLoader inside such layers for batching/deduplication/caching.2
