Writing Batch Functions

The heart of DataLoader is a function that turns an array of keys into an array of aligned values — write it with a Map and the ordering takes care of itself.

The mental model in one sentence

A batch function receives keys and must resolve to an array of the same length, each value at the key's index — the cleanest way to guarantee that is a lookup Map plus keys.map(...).1

The shape of a good batch function

// one query against the data source, then ordered remap
async function batchUsers(keys: ReadonlyArray<string>): Promise<(User | null)[]> {
  const rows = await db.users.whereIn('id', keys as string[]);   // 1 query
  const byId = new Map(rows.map(r => [r.id, r]));
  return keys.map(id => byId.get(id) ?? null);                   // aligned
}

const users: DataLoader<string, User | null> = new DataLoader(batchUsers);
  • Issue one query for all keys (e.g. SQL IN (...) / a MongoDB $in).1
  • Build a Map from the returned rows keyed by id.
  • Return keys.map(key => byId.get(key)), using ?? null so missing keys become null rather than breaking index alignment.1

Type the loader

DataLoader ships its own TypeScript types, so new DataLoader<string, User | null>(batchUsers) gives resolvers full, end-to-end typing and lets context values declare loaders precisely.1

Key idea Never return a shortened array or one in query order. If the DB returns rows in its own order, your Map-and-remap guarantees the loader's index-alignment contract regardless of what the driver ordered.

Grouping a one-to-many batch

For children with an ownerId, query all rows for IN keys, then group by owner and return the list per key (empty array for none) so every key still gets a value:

async function batchPosts(keys: ReadonlyArray<string>) {
  const rows = await db.posts.whereIn('ownerId', keys as string[]);
  const byOwner = new Map<string, Post[]>();
  for (const p of rows) {
    const list = byOwner.get(p.ownerId) ?? [];
    list.push(p);
    byOwner.set(p.ownerId, list);
  }
  return keys.map(ownerId => byOwner.get(ownerId) ?? []);
}
