DataLoader Basics

Install it, construct it with a batch function, and call load — and the event loop does the batching for you.

The mental model in one sentence

You install DataLoader, create an instance with a batch function (new DataLoader(keys => …)), and then call load(key) — the loader coalesces same-tick loads into one batch call.1

Install and a first loader

npm install dataloader

import DataLoader from 'dataloader';

const userLoader = new DataLoader(async (keys: ReadonlyArray<string>) => {
  const rows = await db.users.whereIn('id', keys as string[]);
  const byId = new Map(rows.map(r => [r.id, r]));
  return keys.map(id => byId.get(id) ?? null);
});

const user = await userLoader.load('u1');
  • DataLoader is the default export; usage in TypeScript is typically new DataLoader<Key, Value>(batchFunction).1
  • The batch function receives ReadonlyArray<Key> and must resolve to an array of Value.
  • load(key) returns a Promise for one value; many calls in the same tick become one batch.1

Index alignment is the contract

The batch function's returned array must be the same length as the keys array, with each value at the same index as the key it answers. A string-keyed map plus a remap over keys guarantees this in a table-driven data source.1

Key idea Write the batch function so it returns a value for every key in order. A common trick: build a Map from loaded rows, then return keys.map(key => byId.get(key)) so alignment is automatic.

Load many

When your code needs several keys at once, loadMany(keys) resolves to an array of results and is convenient with Promise.all or a variable-argument consumer.1
