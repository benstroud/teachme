Severity, Options, and Silence

Turn rules into policy — and keep the signal readable.

Three severities, one dial

ValueMeaningExit code
"off" / 0Rule disabledunaffected
"warn" / 1Reported, not blockingunchanged1
"error" / 2Reported, blocking1 when triggered1

This is why "warn" is the right first step when adopting a rule: the team sees the problem, and CI stays green long enough to fix the backlog.1

Options ride behind the severity

export default [
  {
    rules: {
      "eqeqeq": ["error", "always", { "null": "ignore" }],
      "no-console": "warn",
      "example/no-todo": "error",   // namespaced plugin rule
    },
  },
];

Only the elements after the severity reach the rule. For the config above the rule sees context.options equal to ["always", { "null": "ignore" }]. A rule can never read its own severity — that is a linter concern, not a rule concern.2

Silencing, precisely

// one line, with a reason
// eslint-disable-next-line no-console -- CLI output is the feature here
console.log(summary);

// a region
/* eslint-disable no-console */
console.log("still migrating");
/* eslint-enable no-console */

// reconfigure one rule for the rest of the file
/* eslint eqeqeq: "off" */

Two or more dashes introduce a justification, which is worth enforcing by convention: an unexplained disable is indistinguishable from a mistake six months later.1

Keep the signal honest

// eslint.config.js
{
  linterOptions: {
    reportUnusedDisableDirectives: "error",  // defaults to "warn"
    // noInlineConfig: true,                 // ban directives entirely
  },
}
  • Unused directives are dead suppressions. Reporting them turns "we disabled it years ago" into a cleanup task.1
  • --quiet hides warnings while still reporting errors; --max-warnings 0 makes any warning fail the run.3
  • --no-inline-config ignores all directive comments — useful to prove the config alone passes.3
Ask the agent Pick one rule you have disabled inline and explain, in a comment, why it is still needed. If you cannot, delete the directive and let the linter speak.
