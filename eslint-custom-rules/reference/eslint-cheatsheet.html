ESLint Cheat Sheet

The compressed essence of the course. Skim before a lesson, study it fully before an interview.

1. The model

source -> parser -> ESTree AST -> rule visitors -> reports -> formatter
                    (+ tokens, comments)
  • Static analysis: the code is read, never executed.1
  • A rule is a function from an AST node to zero or more messages.2
  • Severity changes reporting and exit codes, not detection.3

2. Flat config skeleton

// eslint.config.js
import js from "@eslint/js";

export default [
  js.configs.recommended,
  {
    files: ["src/**/*.js"],
    languageOptions: { ecmaVersion: 2024, sourceType: "module" },
    linterOptions: { reportUnusedDisableDirectives: "error" },
    plugins: { acme },                     // object map, not an array
    rules: { "acme/no-todo": "error" },
  },
  { ignores: ["dist/**"] },                // global: only key
];
  • Later matching objects win; config is a cascade.4
  • An ignores-only object ignores globally.4
  • Precedence: .js, .mjs, .cjs, .ts, .mts, .cts.4

3. Severity & options

"no-console": "off"      // 0
"no-console": "warn"     // 1  -> exit code unchanged
"no-console": "error"    // 2  -> exit 1
"eqeqeq": ["error", "always", { "null": "ignore" }]
                              ^ context.options = ["always", {...}]
  • Warnings never fail the run unless --max-warnings says so.3
  • Inline: // eslint-disable-next-line rule -- reason.3
  • Stale suppressions: linterOptions.reportUnusedDisableDirectives.3

4. Rule module skeleton

module.exports = {
  meta: {
    type: "suggestion",              // problem | suggestion | layout
    docs: { description: "...", url: "..." },
    schema: [],                      // no options
    messages: { banned: "Do not call {{name}}()." },
    fixable: "code",                 // only if you fix
    hasSuggestions: true,            // only if you suggest
  },
  create(context) {
    const sourceCode = context.sourceCode;
    return {
      "CallExpression[callee.name='eval']"(node) {
        context.report({ node, messageId: "banned", data: { name: "eval" } });
      },
    };
  },
};
  • create() runs once per file; closure state is file-local.2
  • messageId over literal messages: one wording, one place.2

5. Selectors

"CallExpression[callee.name='require']"
"MemberExpression[object.name='console'][computed=false]"
"FunctionDeclaration[params.length>3]"
"Identifier[name=/^on[A-Z]/]"
"IfStatement > BlockStatement CallExpression"
":matches(ArrowFunctionExpression, FunctionExpression)"
"CallExpression:exit"
  • Child >, descendant space, siblings ~ and +.5
  • :exit fires on the way back up — use it to unwind state.5
  • More attributes/pseudo-classes means more specific, so it runs later.5

6. Fixers & suggestions

meta: { fixable: "code" },             // mandatory to fix
fix(fixer) {
  const op = context.sourceCode.getTokenAfter(node.left);
  return fixer.replaceText(op, node.operator + "=");
}

meta: { hasSuggestions: true },        // mandatory to suggest
suggest: [{ messageId: "remove", fix: (f) => f.removeRange(range) }]
  • Fixer: insertTextBefore/After, replaceText, remove, plus *Range variants.2
  • Multiple fixes must not overlap; ESLint re-runs rules up to 10 passes.2
  • Suggestions are stand-alone, chosen by a human, and dropped if the fix returns null.2
  • CLI: --fix, --fix-dry-run, --fix-type.6

7. Options & schema

meta: {
  schema: [{
    type: "object",
    properties: { forbidden: { type: "array", items: { type: "string" } } },
    additionalProperties: false,
  }],
  defaultOptions: [{ forbidden: ["eval"] }],
},
create(context) {
  const [{ forbidden }] = context.options;   // defaults merged under user values
}
  • Validation: wrap -> severity -> stop if off -> copy options -> validate schema.2
  • No schema (or []) means options are rejected; false opts out.2

8. RuleTester

const { RuleTester } = require("eslint");
const ruleTester = new RuleTester({ languageOptions: { ecmaVersion: 2022 } });

ruleTester.run("strict-equality", rule, {
  valid: [{ code: "a === b;" }],
  invalid: [{
    code: "a == b;",
    output: "a === b;",
    errors: [{ messageId: "strict", type: "BinaryExpression" }],
  }],
});
  • At least one valid and one invalid case, or run() refuses.7
  • output asserts the fixed text; errors takes a count or shapes.7

9. Plugin

const plugin = {
  meta: { name: "eslint-plugin-acme", version: "1.0.0" },
  rules: { "no-todo": noTodo },
  configs: {},
};
plugin.configs.recommended = [
  { plugins: { acme: plugin }, rules: { "acme/no-todo": "error" } },
];
module.exports = plugin;
  • Rule ID is namespace/rule-name from the plugins key.8
  • configs are never auto-applied; the user includes them.8
  • Publishing: eslint-plugin-* name, eslint as a peer dependency.8

10. Scope & rollout

const scope = context.sourceCode.getScope(node);   // v9: not context.getScope()
for (const v of scope.variables) {
  const used = v.references.some((ref) => ref.isRead());
}
context.sourceCode.markVariableAsUsed("name", node);
  • Scope kinds: global, module, function, block, class, catch, switch…2
  • Rollout: warn -> measure -> fix or suppress -> error, with --max-warnings 0.6
  • Verify with eslint --print-config <file>.6
