# Starting Point: Apollo GraphQL Gateway & Router

The learner is a self-taught TypeScript backend developer working toward senior
JS/TS + Node.js mastery. He already builds client-facing APIs and now wants to own
the *graph edge*: the layer that sits between many clients and many GraphQL
services. He wants to master the two Apollo gateways — the Node.js @apollo/gateway
(run in-process with Apollo Server) and the standalone Apollo Router — the
supergraph they serve, query planning across subgraphs, router configuration
(authentication, CORS, caching), and operating it with telemetry and deployment —
and to defend the architecture in a senior interview. This lesson set is designed
to be self-contained and independent of all other courses in the repository.
