Rules and event patterns

How the bus decides which consumer gets which event.

A rule is a filter plus a destination

A rule on a bus has two halves: an event pattern (what it matches) and a list of targets (where matches go). Remember the default posture: all matching rules fire. If three rules match the same event, all three targets get it — that is how one event fans out to many consumers without the producer knowing.1

Patterns only mention the fields they care about

You match on source, detail-type, and anything inside detail. Fields you don't list act as wildcards. Compare the event to the pattern:

{
  "source": ["com.acme.orders"],
  "detail-type": ["Order Placed"],
  "detail": {
    "customerId": ["cust_42"]
  }
}

This matches any event that carries that source, that detail-type, and a detail.customerId of cust_42. The rest of the detail doesn't matter.2

Matching semantics that trip people up

These are the rules the AWS docs spell out — internalize them:2

  • Values are arrays: "source": ["a", "b"] means match a OR b.
  • String matching is exact, character-for-character. No case-folding, no trimming.
  • Numbers compare as their string representation: 300, 300.0, and 3.0e2 are not equal.
  • Only the last value listed for a duplicated field is used.
  • A dot in a key is a joining character: detail.state.status is the same as nesting detail > state > status.

Content filtering: matching beyond exact equality

When equality isn't enough, use a comparison operator in place of the value:3

{
  "source": ["com.acme.orders"],
  "detail": {
    "total":  [{ "numeric": [">=", 100] }],
    "region": [{ "prefix": "us-" }],
    "expedited": [{ "exists": true }],
    "status": [{ "anything-but": ["CANCELLED"] }]
  }
}
  • prefix / suffix — string starts / ends with.
  • numeric — range like [">=", 100] or closed [1, 10].
  • exists — true/false for field present or absent.
  • anything-but — a list of values to exclude.
  • wildcard — glob-style "ord_*".
  • equals-ignore-case — case-insensitive equality.
Why this is powerful Routing happens at the bus, before your Lambda ever runs. Filtering early means consumers see only the events they should pay for, and you don't pay Lambda compute for events you'll just discard.
