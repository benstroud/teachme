Lesson 2 of 10Reasoning vs Non-Reasoning LLMs

How a Standard LLM Answers

The fast, fluent, non-deliberate token generator you build most apps on.

The mental model in one sentence

A standard LLM answers by predicting and emitting the next token again and again — with no search, no backtracking, and no plan — so the prompt plus everything generated so far is its entire working memory.1

Autoregressive generation

request = "The capital of France is "
# token-by-token, always conditioned on context + prior output
context = request           # -> "Paris"
context = request + "Paris" # -> "."
context = ...

Each token is sampled from a probability distribution over the vocabulary. This makes output fast and fluent, but it means the model commits to words before the whole answer is "known" to it — there is no pass where it plans first.

What that buys and what it costs

StrengthWeakness
Very fast, natural phrasingOne early wrong token propagates
Great at recall and summarizationWeak on long chains of dependent steps
Cheap (few tokens)No explicit reasoning or self-check
Key idea "Reasoning" is not absent from the model — prompts can still coax step-by-step text out of a standard model via chain-of-thought prompting — but it is not enforced by training, so it is patchy.2
