# Starting Point: Git Merge, Fast-Forward, Pull & Rebase

The learner is a self-taught TypeScript developer working toward senior JS/TS +
Node.js mastery. He uses Git daily but wants a precise mental model of history
integration: when a pull fast-forwards and when it creates a merge, what the merge
commit is, what a rebase rewrites and why SHAs change, what `git rebase --onto`
really does when moving a range onto a different base, and the golden rule about
not rebasing published work plus how to recover when it happens. He wants to master
the commit graph, merge vs rebase, pull modes, conflict resolution, and recovery —
and to defend the choices in a senior interview. This lesson set is designed to be
self-contained and independent of all other courses in the repository.
