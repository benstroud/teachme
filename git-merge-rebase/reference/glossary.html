Git Merge & Rebase Glossary

Every term in this course, in one place. Return here when a lesson uses a word you do not fully own.

The commit graph

commit
A snapshot of the project plus its parent commit(s) and a message; commits form a directed acyclic graph (the history).1
branch
A movable pointer to a commit; creating commits on a branch moves that pointer forward.1
HEAD
The pointer to the currently checked-out branch (or a detached commit).1
merge base
The most recent common ancestor commit of two branches — the point from which they diverged.3
ancestor / descendant
A commit reachable by parent links (ancestor) or by children links (descendant). Branch A is a descendant of B if A can reach B.
diverged
Two branches each have commits the other does not, since their common merge base — the shape that forces a true merge or a rebase.

Merging

fast-forward
A merge where the current branch can simply be moved forward to the merged commit (the merged-in branch is a descendant); no new commit is created.2
true merge / three-way merge
A merge of two diverged histories that combines the two latest snapshots and the merge base, creating a merge commit with two parents.1
merge commit
A commit with more than one parent (typically two), the result of integrating two histories.1
conflict
When both sides changed the same lines; Git marks the file with <<<<<<< HEAD, =======, and >>>>>>> blocks for you to resolve.1
--ff-only / --no-ff
Merge flags: refuse the merge unless it can fast-forward (--ff-only), or always create a merge commit even when a fast-forward would work (--no-ff).2
git merge --abort / --continue
Abort an in-progress merge and restore your pre-merge state, or continue after resolving conflicts.2

Rebasing

rebase
Reapply commits on top of another base tip — take the commits unique to your branch and replay them onto the target, producing new commits.4
rebase --onto
Transplant a range of commits onto a different base: git rebase --onto newbase upstream [branch] replays upstream..branch onto newbase.4
interactive rebase
git rebase -i: reorder, edit, squash, or drop commits in the replay.4
rewrite
Producing new commits with new hashes in place of old ones — the defining effect of rebase.

Integration & recovery

fetch
Download commits and refs from a remote without touching your working tree or current branch.5
remote-tracking ref
A local copy of a remote branch, e.g. origin/main, updated by fetch/pull.5
pull
git fetch followed by an integration (merge by default), or git pull --rebase to rebase instead.5
pull.rebase
A config to make git pull rebase by default.
reflog
A local log of where HEAD and branches have been — the safety net for recovering from a rewrite.6
