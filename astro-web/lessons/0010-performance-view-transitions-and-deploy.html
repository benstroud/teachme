Performance, View Transitions & Deploy

Prefetch, animated navigation, SEO, and matching your host to the render mode.

The mental model in one sentence

Astro's default output is already fast; you then add polish you control — prefetch and View Transitions for navigation, SEO basics, and a deploy target that fits your rendering mode.1

Faster navigation

ToolEffect
PrefetchPreloads linked pages on hover/visibility.2
View TransitionsAnimated, app-like client navigation between pages.3

Before you ship

  • Add a sitemap and canonical URLs for SEO.
  • Keep interactive components as small, intentioned islands.
  • Match the deploy target to the render mode: static hosts for static output, a server adapter where needed.2

A reference shape

static pages (build)      -> CDN/static host
on-demand pages + API     -> server adapter host
islands                   -> ship only where interactivity is needed
navigation                -> prefetch + view transitions
Key idea The performance story is layered: zero JS by default, islands for interactivity, and prefetch/transitions for perception. Deploy is the last mile — pick a host that matches how your pages render.1
