Layouts & Slots

Reusable page shells built from components and slots — no special framework magic.

The mental model in one sentence

A layout is just a component that wraps a page in a shared shell — header, nav, footer — and drops the page content into a <slot />.1

A base layout

---
// src/layouts/Base.astro
const { title = "My Site" } = Astro.props;
---
<html lang="en">
  <head><title>{title}</title></head>
  <body>
    <header><nav>…</nav></header>
    <main><slot /></main>
    <footer>© My Site</footer>
  </body>
</html>

A page then imports the layout and nests its content inside. The shell is authored once and reused everywhere.1

Named slots and fallback content

  • Give a slot a name (e.g. <slot name="head" />) to accept a specific piece of content.
  • A <slot /> can contain fallback content shown when nothing is passed in.2
  • Layouts compose: a page layout can pass slots through to a base layout.2
Key idea Layouts are not a special framework feature — they are components plus slots. That means you can nest them and pass content through deliberately.2
