Styling & Assets

Scoped-by-default styles, global CSS, and where your files should live.

The mental model in one sentence

Styles you write in an .astro component are scoped to that component by default, and static files are served from public/ while imported assets get optimized.1

Scoped vs global styles

<style>
  /* only applies to this component */
  .card { border: 1px solid #ccc; }
</style>

<style is:global>
  /* applies to the whole site */
  body { font-family: system-ui; }
</style>

Scoping means you can name a class .card in ten components without collisions. Use is:global (or a global stylesheet import) for site-wide rules and CSS variables.1

Assets: public vs imported

WhereBehavior
public/Served as-is at the root; not processed.2
src/assets/ (imported)Optimized, hashed, and bundled.2
<Image />Renders an optimized image with width/height set.2
Key idea Reach for scoped styles first; they are the path of least surprise. Import images you want optimized, and keep only true static files in public/.2
