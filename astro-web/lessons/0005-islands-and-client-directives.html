Islands & Client Directives

Opting a component into interactivity — and choosing exactly when it hydrates.

The mental model in one sentence

An island is an interactive component on an otherwise static page: everything stays HTML, and only the components you mark with a client: directive get their JavaScript loaded and hydrated.1

The client directives

DirectiveWhen it hydrates
client:loadImmediately on page load.1
client:idleWhen the browser is idle.
client:visibleOnly once scrolled into view.
client:onlySkip server render; run only in the browser.

Using a React (or Vue/Svelte) component

<Counter client:visible />   <!-- hydrates only when seen -->

Install the matching renderer, then opt an existing framework component into the page with a directive. Islands hydrate in isolation and can load in parallel, so a heavy widget low on the page never blocks the header.2

Key idea Interactivity is a deliberate choice, per component. If you never add a directive, the component is plain HTML and ships nothing to the client.1
