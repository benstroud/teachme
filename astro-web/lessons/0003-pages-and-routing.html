Pages & Routing

Files under src/pages become URLs, and brackets turn a route dynamic.

The mental model in one sentence

Any file you put under src/pages/ becomes a route automatically: the path and filename decide the URL, and brackets make a route dynamic.1

File path to URL

FileURL
src/pages/index.astro/
src/pages/blog.astro/blog
src/pages/blog/[slug].astro/blog/:slug1
src/pages/docs/[id]/edit.astro/docs/:id/edit

Dynamic routes for static builds

---
// src/pages/blog/[slug].astro
export async function getStaticPaths() {
  return [
    { params: { slug: "hello" } },
    { params: { slug: "world" } },
  ];
}
const { slug } = Astro.params;
---
<h1>Post: {slug}</h1>

For a statically generated site, getStaticPaths tells Astro every parameter value to pre-render at build time. With on-demand rendering, the route can instead resolve its parameter at request time.1

Key idea Routing is convention over configuration: you rarely write route tables. Move a file, and the URL changes with it.1
