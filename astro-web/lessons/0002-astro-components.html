Astro Components

The .astro file: a server-only frontmatter fence and an HTML-superset template.

The mental model in one sentence

An .astro component has two halves: a frontmatter fence between --- lines that runs on the server and never ships to the browser, and an HTML template below it that renders the output.1

Anatomy of a component

---
// runs at build/server time — never sent to the browser
const { title } = Astro.props;
const items = ["a", "b", "c"];
---
<h1>{title}</h1>
<ul>
  {items.map((x) => <li>{x}</li>)}
</ul>

Curly braces evaluate JavaScript expressions in the template. Because the frontmatter is server-only, it can read files, query a database, or import data with no client cost.1

Props and composition

  • Read incoming props from Astro.props in the frontmatter.
  • Import other components and use them as tags.
  • Pass children into a component with <slot />.
Key idea The template is a superset of HTML — any valid HTML is valid Astro. The framework adds expressions and scoped styles, but never forces a client runtime on you.1
