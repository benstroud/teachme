# Starting Point: Astro.js Web Framework

The learner is a self-taught TypeScript / JavaScript developer working toward
senior front-end and full-stack mastery. He has built React single-page apps and
understands their cost (client JavaScript, hydration, slower first paint) and now
wants to master Astro, the content-focused web framework: authoring `.astro`
components whose frontmatter runs server-only, file-based routing, layouts and
slots, the islands architecture and client directives, scoped styling and assets,
typed content collections, choosing static vs on-demand rendering with an adapter,
fetching data and writing API endpoints, and shipping a fast, SEO-friendly site.
This lesson set is designed to be self-contained and independent of all other
courses in the repository.
