# JavaScript & Node.js Standard Library Resources

## Knowledge

- [Node.js v22 Documentation & API Reference](https://nodejs.org/docs/latest-v22.x/api/)
  Official documentation for built-in modules (`fs`, `stream`, `http`, `events`, `worker_threads`). Use for: authoritative API signatures and native module behavior.
- [MDN Web Docs: JavaScript Guide](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide)
  Comprehensive guide to JavaScript language mechanics, closures, prototypes, and asynchronous execution. Use for: understanding runtime behavior behind TypeScript types.
- [Node.js Design Patterns (4th Edition) — Mario Casciaro & Luciano Mammino](https://www.nodejsdesignpatterns.com/)
  Authoritative guide to Node.js architectural patterns, stream pipelines, asynchronous control flow, and event-driven design.

## Wisdom (Communities)

- [r/node](https://reddit.com/r/node)
  Community discussions on Node.js core updates, performance tuning, and architectural patterns.
- [Node.js GitHub Discussions](https://github.com/nodejs/node/discussions)
  Direct discussions with Node.js core contributors and maintainers regarding runtime behavior and standard library design.
