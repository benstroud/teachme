ReferenceJS & Node for TypeScript Devs

Glossary

Canonical terms for bridging TypeScript developer mental models to JavaScript runtime & Node.js standard-library behavior.

Runtime & Prototype Model

Prototype chain
The mechanism by which JavaScript objects inherit properties and methods from other objects, underpinning JavaScript's prototypal inheritance model.1
Closure
A function bundled together with references to its lexical scope, enabling state persistence and data encapsulation without objects.
Lexical scope
The scope determined by where code is written, not where it runs. Closures capture it.
Prototype-based inheritance
Inheritance via object links rather than class hierarchies. ES6 class is syntactic sugar over it.

Asynchronous Execution & Event Loop

Event loop
The single-threaded coordination mechanism in Node.js that dispatches asynchronous callbacks, timers, and I/O via microtask and macrotask queues.2
Microtask
A high-priority queue item (Promise callbacks, process.nextTick) that runs immediately after the current stack empties, before the timer/I-O phase.
Macrotask
A lower-priority queue item (setTimeout, setInterval, I/O callbacks) that runs in a later phase of the event-loop pass.
process.nextTick
Runs a callback in the highest-priority micro phase, ahead of normal promise resolution.

Node.js Standard Library & I/O

Buffer
A fixed-size chunk of memory allocated outside the V8 heap, used to handle raw binary data streams in Node.js.3
Stream
A chunk-by-chunk data-processing mechanism that keeps memory usage low and constant for arbitrarily large data.
Stream pipeline
A memory-efficient mechanism (pipeline from node:stream/promises) that composes readable, transform, and writable streams with automatic resource cleanup and error propagation.
node:fs/promises
The promise-based file-system API, preferred over synchronous or callback-based variants in modern Node.js.

Networking & Concurrency

node:http
The module for building native HTTP servers with explicit request/response handling.4
Global fetch
The built-in HTTP client API available globally in modern Node.js, needing no third-party package.
EventEmitter
The observer pattern in Node.js; can be strongly typed in TypeScript via a generic event map.
Worker thread
A separate OS thread from node:worker_threads used to offload CPU-heavy computation so it does not block the main event loop.
