File System, Path & OS Modules

Reading, writing, and resolving paths on the OS — node:fs, node:path, node:os.

Prefer the promise API

Node's node:fs offers three styles. Modern code reaches for the promise-based variant, node:fs/promises, which composes cleanly with async/await and avoids both blocking calls and manual error-first callbacks:1

import fs from "node:fs/promises";
import path from "node:path";
import os from "node:os";

async function readConfigFile(filePath: string) {
  try {
    const resolvedPath = path.resolve(filePath);   // absolute, platform-safe
    const content = await fs.readFile(resolvedPath, { encoding: "utf-8" });
    return JSON.parse(content);
  } catch (error) {
    console.error(`Failed to read config from OS (${os.platform()})`, error);
    throw error;
  }
}

Never concatenate paths with +

Path separators differ (/ on POSIX, \ on Windows). Joining manually with string concatenation is a cross-platform bug waiting to happen. Use path.join or path.resolve so separators are chosen for you:

import path from "node:path";

const configFilePath = path.join(import.meta.dirname, "config", "settings.json");
// => works on Windows and POSIX
Key idea path.resolve returns an absolute, normalized path; path.join just concatenates segments with the correct separator. TypeScript's import.meta.dirname gives you the current module's directory — the modern replacement for the old __dirname.
