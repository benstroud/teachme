# Mission: JavaScript & Node.js Standard Library for TypeScript Developers

## Why
As an experienced TypeScript developer, you already know static typing, interfaces, and generics, but you need to master the underlying JavaScript runtime semantics and Node.js standard library APIs (like `fs`, `streams`, `http`, and `async` primitives) without relying on external third-party frameworks. By mastering core JS runtime mechanics and native Node APIs, you can build high-performance, resilient backend applications with absolute architectural clarity.

## Success looks like
- Understand V8/JS runtime execution, prototype chains, and closure mechanics behind TypeScript constructs.
- Master Node.js standard library modules (`node:fs`, `node:path`, `node:os`, `node:stream`, `node:http`) fluently with native TypeScript.
- Design efficient asynchronous I/O pipelines, stream transformations, and robust error handling.
- Build production-ready network servers and concurrent tasks using native Node.js primitives.

## Constraints
- Focus exclusively on modern ECMAScript and Node.js 22 built-in standard library APIs (`node:*` imports).
- Bridge TypeScript mental models (types as sets, interfaces, generics) directly to their runtime JavaScript equivalents.
- Keep lessons concise, interactive, and grounded in real-world backend tasks.

## Out of scope
- Third-party web frameworks (Express, NestJS, Fastify).
- Frontend UI development and browser DOM manipulation.
