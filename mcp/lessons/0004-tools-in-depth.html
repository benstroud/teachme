Lesson 4 of 10MCP v2

Tools in Depth

A tool is a contract with a model. The schema, the description, the annotations, and the error shape all decide whether the model calls it correctly and whether the call is safe.

Two kinds of error

The spec separates two failure kinds. A protocol error is a JSON-RPC error object, such as an unknown method. A tool execution error is a normal result with isError: true, so the model can read the message and try again.1

The lab proves the split with two calls. A wrong argument type and a missing note both come back as results, not as exceptions:

// Wrong type for a: schema validation fails inside the tool call.
{ "content": [{ "type": "text", "text": "Input validation error: Invalid arguments for tool add_numbers: a: Invalid input: expected number, received string" }], "isError": true }

// Missing note: the callback returns isError itself.
{ "isError": true, "content": [{ "type": "text", "text": "No note with id missing" }] }
Write errors for the model The model reads the text of an isError result. Say what went wrong and what to try next, not just a code. Anthropic's tool guidance makes the same point: errors should be actionable.3

Annotations are hints, not guarantees

The lab sets readOnlyHint on add_numbers and destructiveHint plus idempotentHint on delete_note. The stdio test reads them back from tools/list. These are the hint names the schema defines.2

The spec is explicit about trust: clients MUST treat annotations as untrusted unless they come from a trusted server. A server that marks a dangerous tool as read-only has not made it safe.1 Lesson 9 returns to this.

Design the contract

Anthropic's guidance on tools for agents makes four points that apply directly to MCP tools:3

  • Fewer, higher-level tools. One search_notes that returns matches beats three tools that list, filter, and fetch.
  • Names that say what they do. Namespace by service and resource, so a model can tell notes_search from calendar_search.
  • Return high-signal data. Return the fields the model needs, not internal IDs and MIME types, and offer a concise response when detail is not needed.
  • Bound the output. Claude Code caps tool output at 25,000 tokens by default. Paginate or truncate in your own tool, rather than leaning on the host's cap.4
