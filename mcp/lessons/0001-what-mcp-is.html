What MCP Is

The Model Context Protocol is a standard way for an AI application to reach outside data and actions. Learn the three roles and the three kinds of thing a server can offer.

The three roles

  • Host: the AI application that coordinates and manages one or multiple MCP clients. Examples are a chat app or an IDE assistant.
  • Client: a component that maintains a connection to an MCP server and obtains context from an MCP server.
  • Server: a program that provides context to MCP clients.

The host creates one client for each server, and each client keeps its own connection.1 The server is the part you write. It exposes what it can offer, and the host decides how to use it.

Why a standard The protocol docs describe MCP as a standard interface between an AI application and external systems, so a server written once can serve any compliant host.2 Without it, each host and each tool pair needs its own integration.

Three things a server can offer

The specification defines three primitives. The difference is who decides when each one is used:3

PrimitiveWhat it isWho controls it
ToolsFunctions the model can call, with argumentsThe model discovers and invokes them automatically
ResourcesRead-only context, addressed by URIThe application decides how to include them
PromptsParameterised message templatesThe user selects them, often as a slash command

The specification says "who decides when the prompt is used, not who authors its content". The same holds for each row: the control is about use, not authorship.3

What the protocol carries

Messages are JSON-RPC 2.0. A request names a method, such as tools/call, and gets a result or an error back. Lessons 3 to 5 cover each primitive with working code. Lesson 2 covers which version of the wire format you are speaking, which is the first thing to know before you debug anything.

Draw it (no code)

Pick an assistant you use, such as a chat app with file access. Name its host, its clients, and each server it connects to. For each server, list one capability and say which primitive it would be. Compare with lesson 10 when you finish.

Check yourself

Which role creates one client for each MCP server it connects to?

The host coordinates the clients, and each client maintains one connection to one server.1

Which primitive does the model discover and invoke on its own?

Tools are model-controlled. Resources are application-driven, and prompts are user-controlled.3

Which primitive does the user select explicitly, for example as a slash command?

Prompts are user-controlled. The spec's wording is about who decides when a prompt is used.3
