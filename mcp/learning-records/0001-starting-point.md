# Starting Point: MCP v2 Servers

The learner is a developer who builds software that AI assistants use. No prior MCP experience is recorded. The current protocol revision is 2026-07-28, and the TypeScript SDK at version 2.x implements it; the lessons call that "v2" and call the 2025-11-25 revision the "2025 revision". Lessons 3 to 6 assume working TypeScript and Node.js. Lesson 10 assumes the learner has at least once considered a shell script or a CLI for the same capability, since the decision is about trade-offs the learner must weigh. This set is independent of other courses.
