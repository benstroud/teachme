Customization: Rhai & Coprocessors

The two hooks for behavior the configuration cannot express.

The mental model in one sentence

When configuration is not enough, the router offers two customization hooks into its request pipeline: Rhai scripts (a Rust-embedded scripting language, in-process) and coprocessors (an external service you call, in any language).1

Rhai vs coprocessor

Rhai scriptsCoprocessors
Where it runsInside the router process1An external HTTP service1
LanguageRhai (Rust-embedded)1Any language1
Best forSmall, fast, in-process tweaksComplex logic, existing services

The migration rule of thumb

For each gateway plugin, first check whether the router already has a native config option (e.g. header propagation, OpenTelemetry). Only reach for Rhai or a coprocessor when no option covers it.2

Key idea The customization surface changed shape, not just syntax: where you once wrote an Apollo Server plugin class, you now either flip a YAML option or write a script/service that hooks the same pipeline.2
