Gateway → Router Glossary

Every term in this course, in one place. Return here when a lesson uses a word you do not fully own.

Federation fundamentals

federation
Composing multiple GraphQL services (subgraphs) into one unified API (the supergraph) under a single endpoint.5
subgraph
An individual GraphQL service that contributes part of the federated schema.5
supergraph
The single, composed schema that clients query; built from all subgraphs.5
entity
A type shared across subgraphs, marked with the @key directive.7
@key
The directive naming the field(s) that uniquely identify an entity.7
reference resolver
__resolveReference on a subgraph, called with an entity representation to resolve an entity.7
entity representation
The @key fields plus __typename that the router sends a subgraph to resolve an entity.7
composition
The process that validates and merges subgraph schemas into a supergraph schema.6

The gateway

Apollo Gateway
The earlier Node.js gateway: the @apollo/gateway library run inside Apollo Server.4
RemoteGraphQLDataSource
A gateway class for customizing requests to a subgraph, e.g. adding headers.4
buildService
A gateway hook called once per subgraph to customize its data source.4
gateway plugin
An Apollo Server plugin extending behavior (telemetry, headers, custom logic) in the gateway.3

The router

Apollo Router
The successor: a standalone binary and execution engine for graph-based API orchestration.1
query plan
The router-resolved strategy for fetching a query efficiently across subgraphs.1
router.yaml
The declarative YAML configuration file for all router runtime features.2
Uplink
Apollo-managed service that delivers the supergraph schema to the router automatically.2
graph artifact
An immutable, versioned supergraph schema reference for deterministic deploys.2
hot reload
Reloading the supergraph schema without downtime.2

Customization & migration

Rhai script
A lightweight Rust-embedded scripting language for router customizations.3
coprocessor
An external service the router calls to customize behavior in any language.3
header propagation
Forwarding HTTP headers from the client to subgraphs (a router config option).3
proxy migration
Running gateway and router together and conditionally shifting traffic for a gradual cutover.3
