Indexes & Query Performance Glossary

Every term in this course, in one place. Return here when a lesson uses a word you do not fully own.

Indexes

Index
A data structure storing a small, ordered portion of the collection. MongoDB indexes use a B-tree; the ordering supports equality, range, and returned-sort efficiency.1
Collection scan (COLLSCAN)
What happens with no usable index — MongoDB scans every document to answer a query.1
Index scan (IXSCAN)
Reading only the relevant slice of index keys instead of the whole collection.2
_id index
The unique index MongoDB creates on every collection's `_id`; it can't be dropped.1
Key pattern
The index's fields and directions, e.g. { item: 1, quantity: -1 }. Also the basis of the default index name.1
Single-field index
An index on one field; on an embedded document it serves only whole-document equality, not sub-field queries.1
Compound index
An index over several fields in a fixed order; field order is critical and there is a 32-field limit.3
Index prefix
A leading subset of a compound index's fields; queries on a prefix can use the index.3
Multikey index
An index on an array field; MongoDB stores one entry per distinct element, pointing back to the same document.4

Guidelines & plans

ESR (Equality, Sort, Range) guideline
The recommended ordering of fields in a compound index: equality fields first, then sort, then range.5
Equality / Sort / Range fields
An equality field is an exact match; a sort field orders results; a range field uses an operator like $gt/$lt (or $ne, $nin, $regex).5
In-memory sort (SORT stage)
What MongoDB performs when no index supplies the requested order; it appears as a SORT stage in the plan.6
Covered query
A query answered entirely from the index because all query and projection fields are in it — no FETCH.4
winnerPlan
The plan MongoDB selects, shown in explain's queryPlanner output.2
FETCH
The stage that retrieves the actual documents after an index narrows the matches.2

Properties & types

Unique index
Enforces no duplicate values on the field(s); a compound unique index enforces uniqueness of the combination.7
TTL index
A single-field index on a date that makes MongoDB auto-delete expired documents after expireAfterSeconds.8
Partial index
An index that only covers documents matching a partialFilterExpression, saving space and write cost.9
Sparse index
An index that skips documents missing the indexed field.
Hidden index
An index invisible to the query planner, used to test dropping it without actually removing it.
Text / geospatial / hashed / wildcard indexes
Specialized indexes for $text search, geo queries, hashed sharding, and flexible-schema wildcard fields respectively.9
