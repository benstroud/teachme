Kafka Glossary

Every term in this course, in one place. Return here when a lesson uses a word you do not fully own.

Events & the log

Event
An action, incident, or change recorded by software — e.g. a payment, a click, a reading. A notification (to trigger activity) plus small state, usually JSON, Avro, or Protobuf.1
Kafka event streaming
A data streaming engine that collects, processes, stores, and integrates data at scale.1
Topic
A named category/channel that events are written to; the unit you subscribe to.2
Partition
A shard of a topic — an ordered, append-only log. A topic is split across one or more partitions; ordering is guaranteed within a partition.
Offset
A unique, monotonically increasing id per event within a partition, never reused; events are stored and delivered in offset order.3
Append-only log
The storage model: events are appended to the end of a partition's log and read back in order — the "commit log" idea.

Cluster & reliability

Broker
A Kafka server in the cluster that stores partitions and serves producers and consumers.2
Cluster
A group of brokers working together; the system scales by adding brokers (scale-out).
Replica
A copy of a partition stored on another broker; replication adds durability. The replication factor is the number of copies.
Leader / follower
Each partition has one leader (handles reads and writes) and follower replicas that stay in sync; the leader is elected among them.4
ISR (in-sync replicas)
The set of replicas that are fully caught up with the leader; only ISR members can be elected leader.4
min.insync.replicas
The minimum number of in-sync replicas that must acknowledge a write for it to be accepted with `acks=all`.
KRaft
The modern consensus-based controller for cluster metadata that replaces ZooKeeper.

Clients & semantics

Producer
A client that writes events to topics/partitions, choosing the partition (often by key).2
Consumer
A client that reads events from partitions, tracking its position by offset.2
Consumer group
A set of consumers that cooperate: each partition is assigned to exactly one consumer in the group, splitting the work.2
Rebalance
Reassigning partitions among consumers when a member joins/leaves the group; consumers pause and re-sync during it.
Commit (offset)
Recording the position a consumer has read/graph so the group resumes from there on restart.
acks
The producer's durability setting: 0 (fire-and-forget), 1 (leader writes), all (all ISR write).5
Idempotent producer
A producer that tags records so duplicated retries aren't redelivered — a building block of exactly-once.
At-least-once / at-most-once / exactly-once
The three delivery semantics describing whether a record is guaranteed ≥1, ≤1, or =1 times.5
Log compaction
Retention that keeps, per key, the latest value — a "compact" log used for state-like topics.6
Kafka Streams / Connect / Schema Registry
Streams = stateful processing in Java; Connect = external-system integration; Schema Registry = schema governance for topics.1
