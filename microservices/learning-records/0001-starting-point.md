# Starting Point: Microservices

The learner is a self-taught TypeScript backend developer working toward senior
JS/TS + Node.js mastery. He builds services and wants a precise grasp of the
microservice style: what defines it (independently deployable, business-capability
services), how to find service boundaries, how services communicate (sync vs
async), how decentralized data stays consistent (eventual consistency, saga,
outbox, API composition), the API gateway edge, resilience (timeouts/retries/
circuit breaker), observability across services, and the trade-offs that decide
when not to split (microservice premium, distributed monolith, strangler-fig
migration). This lesson set is designed to be self-contained and independent of
all other courses in the repository.
