# Starting Point: Tailscale

The learner is a self-taught TypeScript / Node.js developer working toward senior
mastery who runs a mix of machines (laptop, home server/Pi, cloud VM, containers)
and wants to stop fighting port forwarding, dynamic IPs, and SSH key sprawl. He
wants to master Tailscale: the mesh WireGuard VPN model, identity-based access, the
tailnet and its 100.x addresses, MagicDNS names, access-control policies (deny-by-
default, directional, locally enforced), subnet routers and exit nodes, Tailscale
SSH, Serve/Funnel, and how to operate a tailnet (status, relays, key expiry,
automation). This lesson set is designed to be self-contained and independent of
all other courses in the repository.
