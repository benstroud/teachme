Reach Devices with MagicDNS

Names instead of IPs: machine names, the .ts.net tailnet domain, and search domains.

The mental model in one sentence

MagicDNS gives every device a DNS name so you can reach it by name (ping monitoring) instead of remembering a tailnet IP.1

How the name is built

Fully qualified name = machine name + tailnet DNS name
  monitoring  +  yak-bebop.ts.net  =  monitoring.yak-bebop.ts.net

MagicDNS adds search domains, so just the machine name resolves: ping monitoring and ping monitoring.yak-bebop.ts.net are equivalent.1

Machine name vs full domain

CaseWhat to type
Your own tailnet devicesJust the machine name (search domain applies).1
Devices shared with youThe full domain name, for security.1
Key idea Names make a tailnet feel like one LAN even though the machines are scattered. If a device cannot resolve names, MagicDNS (or accepting DNS) may be off: tailscale set --accept-dns=false disables it locally.1
