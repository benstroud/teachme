Exit Nodes

Routing all internet traffic through a node you trust — the default route.

The mental model in one sentence

An exit node routes all your internet traffic through it — the default route, not just one subnet — so your public IP and traffic path come from wherever that node lives.1

Advertising and using one

# on the node that will be the exit
tailscale up --advertise-exit-node
#   then approve it in the admin console

# on a client, route everything through it
tailscale up --exit-node=my-server

# keep reaching local LAN devices too
tailscale up --exit-node=my-server --exit-node-allow-lan-access

Exit node vs subnet router

Subnet routerExit node
RoutesSpecific ranges you advertiseAll internet traffic1
Typical useReach a private LANChange egress / secure public Wi-Fi2
Key idea Think of the exit node as "where my traffic appears to come from". It is handy on untrusted Wi-Fi or to reach geo-restricted services — and it composes with a subnet router.2
