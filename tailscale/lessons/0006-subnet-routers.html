Subnet Routers

Extending the tailnet to whole LANs you cannot install Tailscale on.

The mental model in one sentence

A subnet router is a node that advertises a real LAN range — say 10.0.0.0/24 — so the rest of the tailnet can reach devices on that subnet even though Tailscale is not installed on them.1

Setting one up

# 1) enable IP forwarding, then advertise the route
tailscale up --advertise-routes=10.0.0.0/24

# 2) approve the route in the admin console
#    (Machines -> the router -> Edit route settings)

The route must be enabled/approved before other devices can use it. Then any tailnet device can reach 10.0.0.5 as if it were local.1

SNAT and the return route

SettingEffect
SNAT on (default)Source addresses are masqueraded; works out of the box.1
SNAT off (Linux)Source IPs preserved, but LAN devices need a return route for 100.64.0.0/10 via the router.1
Key idea Subnet routers extend the tailnet into networks you cannot install Tailscale on (printers, IoT, a corporate LAN). One node, one advertised range, whole subnet reachable.1
