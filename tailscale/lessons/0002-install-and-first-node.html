Install & Your First Node

Install, authenticate, and read the status output like a native.

The mental model in one sentence

Getting started is three steps: install the client, run tailscale up and authenticate, then repeat on a second device — the two are now on the same tailnet and can reach each other.1

The commands you will live in

# bring this machine onto the tailnet
tailscale up

# what is on my tailnet, and am I connected?
tailscale status

# my tailnet address(es)
tailscale ip -4

# can I actually reach that peer, and how?
tailscale ping other-device

Reading tailscale status

The status output lists every node, its tailnet IP, its owner, and whether the path to it is direct or relayed. That one line tells you a lot about health and performance.2

Key idea A device's tailnet address comes from the 100.64.0.0/10 range. It is stable for that device in the tailnet, so peers can address it even while the public internet IP keeps changing.3
