Putting It Together

A small, routed, reactive SPA — components, signals, services, forms, and HTTP composed.

The mental model in one sentence

Everything composes into one coherent app: a routed component tree that renders views from signals held by injected services that talk to the backend.

A mini todo app

@Service()
export class TodoService {
  private http = inject(HttpClient);
  todos = signal<Todo[]>([]);

  load() {
    this.http.get<Todo[]>('/api/todos').subscribe(all => this.todos.set(all));
  }
  add(text: string) {
    this.todos.update(list => [...list, { id: Date.now(), text, done: false }]);
  }
}

@Component({
  selector: 'app-todo',
  imports: [FormsModule],
  template: `
    <input [(ngModel)]="text" />
    <button (click)="add()">Add</button>
    @for (t of todos(); track t.id) { <p [class.done]="t.done">{{ t.text }}</p> }
  `,
})
export class TodoComponent {
  private service = inject(TodoService);
  todos = this.service.todos;   // read the signal in the template
  text = '';
  constructor() { this.service.load(); }
  add() { this.service.add(this.text); }
}
  • State lives in the service as a signal; the component reads it in the template.1
  • HTTP lives in the service; the component triggers and renders.2
  • @for ... track renders the list; [(ngModel)] captures input.

Route it and go

export const routes: Routes = [
  { path: '', component: TodoComponent },
  { path: 'archive', loadChildren: () => import('./archive.routes').then(m => m.routes) },
];
// AppComponent:  <router-outlet />

The senior recap

  • Components render — templates + bindings + control flow (Lessons 2–3).
  • Signals own state — reactive, computed, exposed readonly (Lesson 4).
  • Services own data — injected with DI, HTTP behind an interface (Lessons 5, 7).
  • Forms capture input — reactive for real forms (Lesson 6).
  • Routing navigates — routes, outlet, lazy-loaded features (Lesson 8).
Key idea The architecture is the point: dumb components, reactive signals, injectable services, and lazy routes. Build each piece small, and assemble a large app from the same five patterns.
