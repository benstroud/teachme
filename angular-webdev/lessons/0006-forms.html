Forms

Capture, validate, and manage user input — reactive forms for serious forms, template-driven for simple ones.

The mental model in one sentence

Angular offers two form approaches: reactive (an explicit model in the class, scalable and testable) and template-driven (the template builds the model via directives).1

Reactive forms: explicit model

import { Component } from '@angular/core';
import { FormControl, FormGroup, Validators, ReactiveFormsModule } from '@angular/forms';

@Component({
  selector: 'app-profile',
  imports: [ReactiveFormsModule],
  template: `
    <form [formGroup]="profile" (ngSubmit)="save()">
      <input formControlName="name" />
    </form>`,
})
export class ProfileComponent {
  profile = new FormGroup({
    name: new FormControl('', [Validators.required]),
  });
  save() { console.log(this.profile.value); }
}
  • The FormGroup/FormControl model is created in the class — explicit and synchronous.1
  • Validation is functions (Validators.required), which scales and is testable.

Template-driven forms: implicit model

import { Component } from '@angular/core';
import { FormsModule } from '@angular/forms';

@Component({
  selector: 'app-signup',
  imports: [FormsModule],
  template: `<input [(ngModel)]="email" name="email" />`,
})
export class SignupComponent {
  email = '';
}

Directives (ngModel) build the model implicitly in the template. Simple to add, but it doesn't scale as well as reactive forms for complex logic.1

Deciding

SituationChoose
Forms are central / complex logicReactive
Tests and reusability matterReactive
Tiny form (e.g. email signup)Template-driven
Key idea For real applications, reach for reactive forms: the model is in the class (easy to test and reason about), and validation is plain functions. Reserve template-driven for trivial captures.
