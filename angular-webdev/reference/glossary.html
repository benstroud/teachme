Angular Glossary

Every term in this course, in one place. Return here when a lesson uses a word you do not fully own.

Components & templates

Component
A TypeScript class with behavior, an HTML template (the DOM it renders), and a CSS selector, configured via @Component.1
Standalone component
An Angular component usable directly via the imports array of another component, without a wrapping NgModule. The default today.1
Selector
The CSS that defines how a component's host element is written in templates (e.g. 'profile-photo').1
Template
The component's HTML that renders onto the page; Angular compiles it to update the DOM as data changes.2
Host element
The DOM element that matches a component's selector; the template renders inside it, and the result is that component's view.1
Component tree
How components compose: parent components render child components, forming an app-wide tree.1
imports
The @Component array listing components/directives/pipes usable in that template.1
@Input / @Output
Decorators for data flowing in to a component and events flowing out.

Binding, control flow & reactivity

Interpolation
{{ expr }} — renders a value into text in the template.2
Property binding
[prop]="expr" — binds a value to an element/component property.2
Event binding
(event)="handler($event)" — listens to an event and calls a method.2
Two-way binding
[(ngModel)]="prop" — bind a value and update it on input; the "banana in a box".2
Control flow blocks
Angular's built-in template control flow: @if, @else, @for (with track), @switch.2
Signal
A wrapper around a value that notifies consumers when it changes; read by calling it (count()).3
computed()
Creates a read-only signal whose value derives from other signals.3
effect()
Schedules a side effect that re-runs when the signals it reads change.3

Services, DI, forms & routing

Service
A TypeScript class sharing data/functionality, decorated with @Service (i.e. @Injectable({providedIn:'root'})).4
Dependency injection (DI)
Supplying dependencies to a class from the outside instead of it creating them; components/directives/services participate automatically.4
inject()
The function used to obtain an injected dependency in a class field initializer or constructor, route guard, etc.4
Reactive form
Forms whose model (FormGroup/FormControl) is created explicitly in the class; synchronous, function-based validation, scalable.5
Template-driven form
Forms whose model is built implicitly by directives (ngModel); simple but less scalable.5
Router
@angular/router; manages SPA navigation via Routes, Outlets, and Links.6
Routes
The configuration mapping URL patterns to components to render.6
RouterOutlet / RouterLink
<router-outlet> is the placeholder where the active route component renders; routerLink navigates without a page reload.6
HttpClient
@angular/common/http client for typed HTTP requests; set up with provideHttpClient().7
