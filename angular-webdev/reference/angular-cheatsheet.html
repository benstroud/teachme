Angular Cheat Sheet

The compressed essence of the course. Skim before a lesson, study it fully before an interview.

1. Start a project

npm i -g @angular/cli      # or: npx @angular/cli
ng new my-app              # scaffold (standalone by default)
ng serve                  # dev server on localhost:4200
ng generate component hero

ng new creates a CLI project with src/, and components are standalone by default.1

2. A component

import { Component, Input, Output, EventEmitter } from '@angular/core';

@Component({
  selector: 'app-user',                       // host element name
  template: `<h2>{{ name }}</h2><button (click)="vote()">up</button>`,
  styles: [`h2 { color: var(--accent); }`],   // scoped to this component
})
export class UserComponent {
  @Input() name = 'anon';                     // data in
  @Output() voted = new EventEmitter<number>();  // event out
  vote() { this.voted.emit(1); }
}
  • Standalone by default; imports: [OtherComponent] to use others.2
  • template/styles inline, or templateUrl/styleUrl.

3. Template bindings & control flow

<p>{{ user.name }}</p>                                  <!-- interpolation -->
<img [src]="picUrl" />                                  <!-- property binding -->
<button (click)="save($event)">Save</button>             <!-- event binding -->
<input [(ngModel)]="name" />                            <!-- two-way -->

@if (user.tier > 5) { <b>VIP</b> } @else { <i>regular</i> }

@for (item of items; track item.id) { <li>{{ item.name }}</li> }
  • @for requires a track expression.3
  • Two-way is "banana in a box" [(ngModel)].3

4. Signals for state

import { signal, computed, effect } from '@angular/core';

const count = signal(0);            // writable
count.set(3);  count.update(v => v + 1);
const double = computed(() => count() * 2);   // derived, readonly

// in a template you read them directly: {{ count() }}
effect(() => console.log('count', count()));
  • Read a signal by calling it; Angular tracks it and re-renders on change.4
  • asReadonly() exposes a read-only view to consumers.

5. Services & DI

import { Service, inject } from '@angular/core';

@Service()                                // = @Injectable({providedIn:'root'})
export class CartService {
  items = signal<string[]>([]);
  add(s: string) { this.items.update(list => [...list, s]); }
}

@Component({ /* ... */ })
export class Navbar {
  private cart = inject(CartService);     // dependency injection
}
  • @Service is a root singleton shorthand.5
  • Inject with inject() in field initializers or constructors.5

6. Forms

// Reactive — explicit model in the class
import { FormControl, FormGroup, Validators, ReactiveFormsModule } from '@angular/forms';

profile = new FormGroup({
  name: new FormControl('', [Validators.required]),
});

// template:
// <form [formGroup]="profile">
//   <input formControlName="name" />
// </form>
  • Reactive forms: model in the class, synchronous, function-based validation, scalable.6
  • Template-driven: directives (ngModel) build the model implicitly — fine for tiny forms.6

7. HTTP & data

import { provideHttpClient, withFetch } from '@angular/common/http';
// app config: providers: [provideHttpClient()]

import { HttpClient } from '@angular/common/http';
import { inject } from '@angular/core';

interface User { id: number; name: string; }
const http = inject(HttpClient);
users = http.get<User[]>('/api/users');   // Observable (or httpResource for signals)
  • Provide via provideHttpClient().7
  • Request typed responses; httpResource bridges to signals for async data.7

8. Routing

import { provideRouter, Routes } from '@angular/router';
import { HomeComponent } from './home.component';

export const routes: Routes = [
  { path: '', component: HomeComponent },
  { path: 'users', loadChildren: () => import('./users.routes').then(m => m.routes) }, // lazy
];
// app config: providers: [provideRouter(routes)]

// template:  <router-outlet />
// nav:       <a routerLink="/users">Users</a>
// go():      this.router.navigate(['/users'])

Routes map a URL to a component; the outlet renders it; links navigate client-side.8

9. Design checklist

  • Split into components — a component per concern; keep templates small.
  • Own state in signals in services; expose asReadonly(); derive with computed().
  • Pass data down with @Input, raise events with @Output, not via direct child access.
  • Use reactive forms for any real form; template-driven for trivial ones.
  • Route by feature and lazy-load with loadChildren.
  • Keep components dumb; put data + HTTP in injectable services.
