# Starting Point: Angular Web Development

The learner is a self-taught TypeScript developer on AWS, working toward senior
JS/TS + Node mastery. He is deeply comfortable with TypeScript, Node, and
type-safe tooling, and is an experienced developer overall, but has done most of
his front-facing work in other frameworks. He wants to add Angular — a
batteries-included, standalone-first, structure-oriented SPA framework — to his
toolkit and build idiomatic applications at a senior level. Node 22 + npm are
available locally. His gap is Angular's current model: the CLI and project
anatomy, standalone components and the component tree, template data binding and
control flow, signals for reactive state, dependency injection and services,
forms, HttpClient/data access, and routing. He wants to assemble realistic,
componentized, routed Angular apps and defend that architecture in a senior
interview. This lesson set is self-contained and independent of all other courses
in the repository.
