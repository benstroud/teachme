# Advanced TypeScript Resources

## Knowledge

- [Type-Level TypeScript (free online course) — Gabriel Vergnaud](https://type-level-typescript.com/)
  The gold standard for *type-level programming*. Chapter 1 "Types are just data" frames
  types as sets of values. Use for: conditional types, `infer`, recursion, the set model.
- [TypeScript Handbook — Type Compatibility](https://www.typescriptlang.org/docs/handbook/type-compatibility.html)
  Official source on structural subtyping and assignability. Use for: why "B assignable to A"
  works, structural typing, function parameter/return variance.
- [TypeScript Handbook — Creating Types from Types](https://www.typescriptlang.org/docs/handbook/2/types-from-types.html)
  Official reference for generics, conditional, mapped, template-literal, and indexed-access types.
  Use for: authoritative syntax and semantics of every type operator.
- [Total TypeScript — Matt Pocock](https://www.totaltypescript.com/)
  Exercise-driven workshops (150+ exercises) on generics, transformations, advanced patterns,
  builder pattern. Use for: deliberate practice once a concept is understood. (Paid; free tutorials too.)
- [Type Hierarchy / set framing — Iván Ovejero](https://ivov.dev/notes/typescript-and-set-theory)
  Concise notes mapping TS to set theory (never = ∅, unknown = universal set). Use for: quick refresher.
