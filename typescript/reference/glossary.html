Glossary

Advanced TypeScript — the canonical vocabulary. Adhered to in every lesson.

The Set Model

Type (as a set)
A type is the set of all values that belong to it. Reasoning about types as sets is the foundation of everything else here.
string = the set of every possible string value.
Literal type
A type whose set contains exactly one value.
"on" is a set of size 1; it is a subset of string.
Assignability
"B is assignable to A" means a B value is accepted where an A is expected. Equivalent to B ⊆ A — B's set is a subset of A's.
Subtype / supertype
B is a subtype of A when B ⊆ A (B is narrower). A is then the supertype (wider). Subtypes are assignable to supertypes.
Structural typing
TypeScript decides assignability by an object's shape (its members), not by its declared name. An object with all the required members fits.
Union A | B
Set union (∪) — a value in A or B. Wider than either part.
Intersection A & B
Set intersection (∩) — a value in A and B. For object types, this combines members (narrower).
never
The empty set (∅). No value has this type. It is the subtype of every type and the absorbing element of unions (T | never = T).
unknown
The universal set — contains every value. The supertype of every type. You must narrow it before use. The type-safe top type.
any
An escape hatch that disables type checking. Assignable to and from everything. Not a set — a hole in the type system. Avoid in senior code.

Narrowing & Control Flow

Narrowing
Using a runtime check to shrink a type's set within a branch — ruling out members that the check excludes.
Inside if (typeof x === "number"), string | number ⟶ number.
Control-flow analysis
TypeScript's engine that tracks the most specific type at every point along every code path (branches, loops, assignments, early returns).
Type guard
Any expression TypeScript recognizes as narrowing: typeof, instanceof, in, equality, truthiness.
Type predicate
A user-defined guard: a function whose return type is arg is T. Callers narrow on a true result. TS trusts the body — it does not verify it.
function isFish(p: Fish | Bird): p is Fish
Discriminant / Discriminated union
A union whose members share a common literal property (the discriminant), letting a switch narrow each case cleanly.
{ kind: "circle" } | { kind: "square" } — kind is the discriminant.
Exhaustiveness check
Assigning the value to never in a default branch so that an unhandled union member becomes a compile error. Relies on never being the empty set.
The null trap
A JS quirk: typeof null === "object". Use x != null (loose !=) to exclude both null and undefined.

Generics

Generic
A function, type, or class parameterized by one or more types. Think: a function whose arguments are sets, returning a set.
Type parameter
The variable in angle brackets (<T>) standing for a type the caller supplies or the compiler infers.
Type-argument inference
The compiler deducing a type parameter from the values passed, so you rarely write <T> explicitly.
Constraint (extends)
An upper bound on a type parameter. T extends X means T's set ⊆ X's set — the same subset meaning as in conditional types. Not class inheritance.
keyof T
The union of T's property-name literals. keyof {a:1; b:2} = "a" | "b".
Indexed access type T[K]
The type of property K on T. Tracks the exact value type, e.g. {a:number}["a"] = number.

Variance

Variance
How the subset relation ⊆ between types is transformed when they're wrapped in a compound type (array, function parameter, function return). Either preserved, flipped, dropped, or both-ways.
Covariant
Preserves the direction: if Cat ⊆ Animal then the wrapped type does too. Holds for output positions — function return types and readonly arrays.
() => Cat is assignable to () => Animal.
Contravariant
Flips the direction. Holds for input positions — function parameters (under strictFunctionTypes). A function taking the wider type is assignable where a narrower-parameter type is expected.
(a: Animal) => void is assignable to (c: Cat) => void.
Invariant
Neither direction is safe. The logically-correct variance for a read-write slot (e.g. a mutable array, which is both read and written).
Bivariant
Both directions accepted — deliberately unsound, kept for ergonomics. TS uses it for method parameters and treats mutable arrays as covariant for the same reason.
"Demand less, deliver more"
The function-assignability rule: A is assignable to B when A's parameters are wider (contravariant) and its return is narrower (covariant).
