# Mission: Advanced TypeScript (toward senior JS/TS, Node.js)

## Why
Ben is a self-taught, productive TypeScript developer who wants to level up to a
genuine senior bar — the person on the team who untangles gnarly type errors,
designs APIs others can't misuse, and reasons about the type system from first
principles rather than pattern-matching. The driver is career growth and
interviews, plus general senior-level fluency across JS/TS and Node.js.

## Success looks like
- Read and diagnose *any* TypeScript error, including cryptic generic/inference ones.
- Author reusable generic utilities and mapped/conditional types others depend on.
- Design APIs and function signatures where misuse is a compile error and autocomplete is delightful.
- Do real type-level programming: conditional types, `infer`, template literals, recursion.
- Operate at a senior level across the broader JS/TS + Node.js stack, not just types.

## Constraints
- Self-taught with foundational gaps *under* the advanced material — we deliberately
  shore up the bedrock (sets, assignability, variance) rather than skipping to tricks.
- Learns best by doing: short lessons, tight feedback loops, tangible win each session.

## Out of scope (for now)
- Framework-specific typing (React/Vue/etc.) — revisit once core type system is solid.
- Build tooling / bundler internals — adjacent, not the current focus.
