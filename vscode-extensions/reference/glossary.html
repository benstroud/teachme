VS Code Extension Glossary

Every term in this course, in one place. Return here when a lesson uses a word you do not fully own.

Architecture

VS Code extension
A package that adds features to VS Code, described by a manifest and loaded into the extension host.2
extension host
The separate process that runs extensions, isolating them from the UI for stability and performance.3
extensionKind
A manifest field (workspace / ui) expressing where an extension prefers to run.3
activate()
The entry function called once when a registered activation event fires.2
deactivate()
Optional cleanup called on shutdown; returns a Promise if async.2
ExtensionContext
The object passed to activate(); holds subscriptions and extension storage.2
disposable
An object with a dispose() you push into context.subscriptions for clean teardown.2

Manifest

manifest
The package.json describing the extension: ID, entry point, engine, contributions.2
publisher + name
Combined as ., the unique extension ID.2
main
The entry point file that exports activate and deactivate.2
engines.vscode
The minimum VS Code API version the extension supports.2
activationEvents
The declared events that cause the extension to load.4
contributes
The declared additions to VS Code (commands, menus, settings, views).5

Contributions

contribution point
A JSON declaration in contributes that extends VS Code functionality.5
command
A named action a user can invoke, shown in the Command Palette.5
menu
Where a command appears (context menu, editor title, etc.), organized in groups.5
keybinding
A keyboard shortcut mapped to a command, often with a when clause.5
configuration
Settings the extension exposes to users.5
view
A UI surface such as a tree view in the sidebar.7

API surfaces

vscode module
The API imported by the extension to interact with the editor.2
commands
Register/dispatch commands programmatically.6
window
Messages, quick picks, status bar, notifications, and visible editors.6
workspace
Open folders, files, configuration, and document access.6
webview
An HTML/CSS/JS panel rendered by the extension, with message passing.8

Language features

language configuration
Brackets, comments, and auto-closing rules for a language.
syntax highlighting
A TextMate grammar (or semantic tokens) that colors tokens.
snippet
A reusable code template surfaced as completions.
language server (LSP)
A separate process implementing the Language Server Protocol, used for rich features.9

Ship it

bundling
Combining sources into one file (esbuild/webpack) for speed and web support.12
.vscodeignore
The file listing what to exclude from the packaged extension.12
vsce
The CLI that packages and publishes extensions.13
VSIX
The installable extension package file format.13
Marketplace
The public registry where extensions are discovered and installed.13
PAT
A personal access token used by vsce to publish, scoped to Marketplace (Manage).13
Open VSX
An alternative registry used by non-Microsoft VS Code builds.
