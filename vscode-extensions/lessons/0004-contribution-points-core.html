Lesson 4 of 10VS Code Extensions

Contribution Points (Core)

Commands, menus, keybindings, and settings — declaring what you add to VS Code.

The mental model in one sentence

Contribution points are JSON declarations in the contributes field that add things to VS Code — commands, menus, keybindings, and settings — so the workbench itself knows about them.1

The four you will use first

PointAdds
commandsNamed actions with titles (Command Palette).1
menusWhere commands appear (context menus, editor title, …).1
keybindingsKeyboard shortcuts, often with a when clause.1
configurationUser settings your extension reads.1

The declarations connect to code

"contributes": {
  "commands": [
    { "command": "acme.format", "title": "Format File" }
  ],
  "menus": {
    "editor/context": [
      { "command": "acme.format", "group": "1_modification@1" }
    ]
  },
  "keybindings": [
    { "command": "acme.format", "key": "ctrl+alt+f", "when": "editorFocus" }
  ]
}

Menu items live in groups (e.g. 1_modification) and can be ordered within a group with an @ suffix like @1.1

Key idea Declare a contribution and it appears in the UI automatically; then implement the matching command in code with the exact same id. Declaration and implementation must agree.2
