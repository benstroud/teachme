Publishing & Deployment

vsce, VSIX, the Marketplace, PATs, platform targets, and CI releases.

The mental model in one sentence

Deployment is vsce: package a VSIX, publish to the Marketplace with a publisher account and a scoped PAT — and automate it in CI.1

Package and publish

npm i -g @vscode/vsce
vsce package                 # makes my-ext-0.0.1.vsix
vsce publish                 # uploads to the Marketplace
vsce publish --packagePath my-ext-0.0.1.vsix

Publishing needs a publisher in the Marketplace and a PAT scoped to Marketplace (Manage) across All accessible organizations; the wrong scope yields 403/401.1

Details that bite

Automate the release

A CI job can build, test, and publish on a tag — the standard pattern for a repeatable release.2

Key idea Treat a release like any shipped artifact: version bump, automated build/test, publish from CI, and be deliberate about platform targets and Open VSX (a separate registry).1
