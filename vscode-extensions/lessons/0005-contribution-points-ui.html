Contribution Points (UI)

Sidebar views, the status bar, quick picks, and notifications.

The mental model in one sentence

Beyond commands, contribution points let you add UI surfaces to the workbench — a sidebar tree view, a status bar item — and drive interactions with quick picks and notifications.1

Surfaces and their declarations

SurfaceHow it is added
Tree view (sidebar)Contribute a view, then implement a TreeDataProvider.1
Status bar itemCreate one at runtime with window.createStatusBarItem.
Quick pick / notificationCall window.showQuickPick / showInformationMessage.

A tree view, end to end

// manifest
"contributes": {
  "views": { "explorer": [ { "id": "acme.items", "name": "Items" } ] }
}

// code
vscode.window.registerTreeDataProvider("acme.items", {
  getChildren: (el) => el ? [] : [{ label: "Item A" }],
  getTreeItem: (el) => el,
});

The declaration places the view in the UI; the provider supplies its data. Each registered provider is a disposable.1

Key idea The manifest declares the shape of a surface (id, place, title); code supplies its content and behavior. Keep the two in sync by id, just like commands.2
