Language Features

The ladder from declarative grammar and snippets to a full language server.

The mental model in one sentence

Language support is a ladder: start with declarative pieces (configuration, grammar, snippets), add programmatic features when needed, and graduate to a language server when the logic gets rich.1

The ladder

LevelExampleHow
DeclarativeBracket/comment rules, snippetscontributes (languages, snippets)2
DeclarativeSyntax highlightingA TextMate grammar2
ProgrammaticGo to definition, hoversAPI providers or a server
RichFull language serviceA language server (LSP)1

Why graduate to LSP

  • Your analysis lives in its own process, so it scales and stays decoupled.1
  • The same server can serve many editors, not just VS Code.1
  • It gives you a standard feature set: completions, hovers, diagnostics, and more.1
Key idea Do not start with a language server. Add the cheapest level that solves your problem; the LSP path is a deliberate investment for breadth and reuse.1
