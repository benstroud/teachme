nvm Cheat Sheet

The compressed essence of the course. Skim before a lesson, study it fully before an interview.

1. The model

one global Node -> drift
per-project pin (.nvmrc + engines) -> reproducible
  • A single runtime cannot serve projects on different majors.1

2. Install & source

curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.8/install.sh | bash
export NVM_DIR="$HOME/.nvm"
[ -s "$NVM_DIR/nvm.sh" ] && . "$NVM_DIR/nvm.sh"   # in ~/.zshrc or ~/.bashrc
  • nvm is a sourced shell function, not a global binary.1

3. Core commands

nvm install --lts        nvm use 20        nvm ls
nvm current              nvm which 20     nvm exec 18 node -v
nvm alias default 20
  • exec runs once under another version without switching.1

4. Pin with .nvmrc

echo "20" > .nvmrc        # commit it
nvm use                   # reads .nvmrc
nvm use --install-if-missing
  • Pin a major for latest patch, or an exact version for reproduction.1
  • Also declare intent in package.json engines.3

5. LTS vs Current

Current -> Active LTS -> Maintenance -> End-of-Life
22 Jod (Maint)  24 Krypton (Active LTS)  26 Current
  • Production normally tracks Active LTS.2
  • Modern lines: ~12 months active, ~18 months maintenance.2

6. Aliases & globals

nvm alias default 20
nvm alias work 20.11.1
nvm install 20 --reinstall-packages-from=18
  • Globals are per version; migrate them when you switch.1

7. Team reproducibility

// package.json
"engines": { "node": ">=20" },
"packageManager": "pnpm@9.1.0"
  • Corepack runs the pinned package manager.4
  • CI should read node-version-file: .nvmrc.3

8. Alternatives

nvm-windows (Windows)  •  fnm (fast, cross-platform)
Volta (per-project, shell-agnostic)  •  asdf (multi-language)
  • Standardize on one manager per team.6

9. Troubleshooting

which node              # what is actually on PATH
nvm current             # what nvm thinks
source ~/.zshrc         # if nvm is not found
  • Ask: is nvm sourced? what does which node say?1

10. Workflow checklist

  • Clone, then nvm use --install-if-missing.
  • Install deps with the pinned package manager.
  • Confirm with node -v and nvm current.
  • Upgrade deliberately: install the new line, migrate globals, move default.
  • Keep CI reading .nvmrc, not a hard-coded version.
