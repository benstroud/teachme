nvm Glossary

Every term in this course, in one place. Return here when a lesson uses a word you do not fully own.

Versions & releases

Node.js version
A runtime release identified by a semver number, e.g. 20.11.1.
semver
Major.minor.patch numbering; ranges like ^20 or ~20.11 select versions.5
Current
The newest release line, still stabilizing; not yet LTS.2
LTS (Long Term Support)
A line promoted for stable, long support — the default choice for production.2
Active LTS / Maintenance
LTS phases: active feature/backport support, then maintenance fixes only.2
End-of-Life (EOL)
The date a line stops receiving support.2
codename
A friendly name for an LTS line (e.g. Krypton, Jod).2

nvm mechanics

nvm
Node Version Manager: a POSIX-compliant bash script (a shell function) to manage multiple Node versions.1
NVM_DIR
The directory nvm installs into and sources from.1
shell function
A function defined in your shell, not a global binary — it only exists where sourced.1
PATH
The list of directories the shell searches for commands; nvm rewrites it to point at a version.
rc file
A shell startup file (~/.bashrc, ~/.zshrc) where nvm is sourced.1
alias
A named version pointer (e.g. default, lts/*) managed with nvm alias.1
default alias
The version used when a new shell starts with no .nvmrc.1
nvm which
Shows the path to the node binary for a version.1
nvm exec
Runs a command under a specific Node version.1

Project pinning

.nvmrc
A file in a project naming the Node version nvm should use.1
--install-if-missing
An nvm use flag that installs the requested version if absent.1
engines
A package.json field declaring the expected Node/npm versions.4
engine-strict
An npm setting that turns engines mismatches into install failures.4
devEngines
A newer package.json field to declare/enforce runtime and package manager.4

Team & tooling

Corepack
A Node-bundled bridge that runs the package manager a project pins.3
packageManager
A package.json field naming the package manager and version (pinned via Corepack).3
CI matrix
Running CI across multiple Node versions to verify compatibility.

Alternatives

nvm-windows
A separate Windows implementation (nvm itself targets POSIX shells).6
fnm
A fast, cross-platform Node version manager.7
Volta
A toolchain manager that pins tools per project, shell-agnostic.8
asdf
A multi-language version manager with Node plugins.9
