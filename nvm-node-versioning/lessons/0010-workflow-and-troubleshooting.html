Lesson 10 of 10nvm · Node Version Management

Workflow & Troubleshooting

Clone → use → install, plus the fixes for the common drift symptoms.

The mental model in one sentence

A clean version workflow is: clone → nvm use (auto-installs) → install deps → work, with a short troubleshooting list for when the shell is using the wrong Node.1

The reference workflow

git clone <repo> && cd <repo>
nvm use --install-if-missing     # honors .nvmrc
npm ci                           # or pnpm install via Corepack
node -v && nvm current           # confirm

# upgrading a project
nvm install 22 --reinstall-packages-from=20
nvm alias default 22

Troubleshooting

SymptomFix
nvm: command not foundSource nvm in this shell/rc file.1
Wrong version after useCheck which node; another manager may shadow it.1
Globals missingReinstall them for this version.1
CI differs from localMake CI read .nvmrc.2
Key idea When versions misbehave, always ask two questions: is nvm sourced in this shell? and what does which node say? Those two answers resolve most drift.1
