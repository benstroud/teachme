Lesson 4 of 10nvm · Node Version Management

The Core Commands

install, use, ls, current, which, exec — and how to read the state.

The mental model in one sentence

Everyday nvm is a handful of verbs: install a version, use it, list what you have, inspect the current one, and run a command under a specific version with exec.1

The commands you will actually type

nvm install 20          # install a major (latest 20.x)
nvm install --lts       # install the latest LTS
nvm use 20              # switch this shell to 20.x
nvm ls                  # installed versions
nvm current             # active version in this shell
nvm which 20            # path to that version's node
nvm exec 18 node -v     # run once under 18, without switching
nvm alias default 20    # version for new shells

How to read the state

CommandAnswers
nvm lsWhat is installed (and the aliases).1
nvm currentWhat this shell is using now.1
nvm which VERSIONWhere that version lives on disk.1
Key idea nvm exec is the underrated one: it runs a single command under another version without disturbing your shell — perfect for a quick compatibility check.1
