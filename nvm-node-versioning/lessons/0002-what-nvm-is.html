Lesson 2 of 10nvm · Node Version Management

What nvm Is

A sourced shell function that rewrites PATH per shell — not a global binary.

The mental model in one sentence

nvm is a POSIX shell function, not a global binary: it lives in the shell that sourced it and switches which node your PATH points at, per shell.1

What that means in practice

Because it is a function…Consequence
It is defined by sourcing a scriptAdd it to your shell rc file.1
It edits PATH per shellEach terminal can run a different version.1
It is not on disk as /usr/bin/nvmNon-interactive shells may not find it.1

Where it lives

export NVM_DIR="$HOME/.nvm"
[ -s "$NVM_DIR/nvm.sh" ] && \. "$NVM_DIR/nvm.sh"

That snippet goes in ~/.bashrc or ~/.zshrc. Every new interactive shell sources it, defining the nvm function and setting up the PATH shims.1

Key idea If a script, cron job, or IDE task says nvm: command not found, it is not broken — that shell simply never sourced the function. Source nvm explicitly or call the versioned binary directly.1
