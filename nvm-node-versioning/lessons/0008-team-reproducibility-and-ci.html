Lesson 8 of 10nvm · Node Version Management

Team Reproducibility & CI

Pin Node and the package manager, then make CI read the same file.

The mental model in one sentence

Reproducibility is two pins plus one mirror: pin Node (.nvmrc + engines), pin the package manager (Corepack packageManager), and make CI use exactly those.1

The project declarations

// package.json
{
  "engines": { "node": ">=20" },
  "packageManager": "pnpm@9.1.0"
}

# .nvmrc
20

# CI (GitHub Actions sketch)
- uses: actions/setup-node@v4
  with:
    node-version-file: .nvmrc
    cache: pnpm

What each pin does

PinEnsures
.nvmrcLocal nvm picks the intended Node.3
enginesIntent is declared; enforce stricter with engine-strict.1
packageManagerCorepack runs the pinned manager version.2
Key idea The best CI says node-version-file: .nvmrc rather than hard-coding a version. Two sources of truth always drift; one file does not.3
