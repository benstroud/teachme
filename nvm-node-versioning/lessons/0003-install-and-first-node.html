Install & First Node

Script, source, install LTS, verify — the bootstrap sequence.

The mental model in one sentence

Install the nvm script, source it from your rc file, then nvm install --lts — from that point you have a Node you can switch to instead of a single global one.1

The install steps

# 1) run the install script (see the nvm README for the current URL)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.8/install.sh | bash

# 2) ensure your rc file sources nvm, then reload the shell
source ~/.zshrc      # or ~/.bashrc

# 3) install a version and switch to it
nvm install --lts     # latest LTS
nvm use --lts

# 4) verify
node -v
nvm current

Why --lts first

LTS lines are the stable, long-support choice for most work; install Current only when a project needs it.2

Key idea Always verify with nvm current and node -v after switching. A shell that did not source nvm will still show the old binary.1
