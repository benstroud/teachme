Lesson 6 of 10nvm · Node Version Management

LTS, Current & the Release Schedule

Current → Active LTS → Maintenance → EOL, and choosing a support posture.

The mental model in one sentence

Node release lines move through phases — Current → Active LTS → Maintenance → End-of-Life — and each LTS line gets a codename; production should normally track LTS, not Current.1

The phases

PhaseWhat it means
CurrentNewest line, still stabilizing; may change.1
Active LTSStable, receives features/backports; the safe default.1
MaintenanceCritical fixes only; plan to upgrade.1
End-of-LifeNo more support; upgrade now.1

Reading the schedule

line    status        codename    EOL
22.x    Maintenance   Jod         2027-04-30
24.x    Active LTS    Krypton     2028-04-30
26.x    Current       (—)         2029-04-30

Modern lines get roughly 12 months of active support, then about 18 months of maintenance, with dates subject to change.1

Key idea Choose the runtime by support posture, not by "newest". LTS for production; Current only when a project explicitly needs an unreleased capability.2
