Why a GraphQL API

A client and a server agree on a shape — the client asks for exactly the fields it wants, and the server is bound to return that shape.

The mental model in one sentence

GraphQL is a query language and a runtime contract: the client sends a selection of fields, and the server answers with exactly that selection — no more, no less.1 Apollo is the toolset (server library, client library, gateway, and composition tooling) for building and operating that layer in TypeScript.

Where it belongs: the client-facing edge

Your API sits between many clients (web, mobile) and your data or services. REST gives you fixed routes per resource; each screen often needs a different blend of that data, so you end up with either a fat payload (over-fetching) or several round-trips (under-fetching). A GraphQL layer lets each client state its exact needs in one request.2

Key idea GraphQL is not "one endpoint for everything". It is a typed contract: the schema names every field and its type, so a bad request fails at the type level, before a database is ever touched.

What a GraphQL layer gives you

PropertyWhat it means in practice
Schema-first contractThe schema (written in SDL) is the single source of truth for every field, type, and relationship.
Client-driven selectionEach client fetches the exact fields it renders; over/under-fetching disappears by design.
Type safety & validationQueries are validated against the schema before execution; the same schema drives codegen for clients.
One round-tripA single request composes many resources (author + books + reviews) into one response.
Strong toolingApollo's Explorer, Apollo Client's cache, and the Router turn the contract into a managed layer.

When NOT to reach for it

  • Tiny, fixed, cache-heavy public APIs — a plain REST/JSON API is simpler, and HTTP caching is easier to reason about. GraphQL's flexibility is a cost if you have one screen.2
  • When clients are generic/unruly and you cannot count on them declaring typed selections.
  • For server-to-server, service-to-service calls where both ends are internal and you control them — that hop needs a different, more binding protocol than a client query language.

The Apollo toolset at a glance

PieceRole
Apollo ServerThe Node library that turns a schema + resolvers into a running GraphQL endpoint.
