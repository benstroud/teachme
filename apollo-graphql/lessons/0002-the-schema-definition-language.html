The Schema Definition Language (SDL)

Every field your clients can ask for, written down once — the single source of truth for the whole layer.

The mental model in one sentence

SDL is the text a schema is written in: you name types (records of typed fields), and the root Query/Mutation types name the entry points clients call.1

The building blocks

scalar DateTime

enum OrderStatus { CREATED FULFILLED CANCELLED }

type Book {
  id: ID!
  title: String!
  price: Float
  tags: [String!]!
  author: Author!
}

type Author {
  id: ID!
  name: String!
  books: [Book!]!
}

input BookFilter { minPrice: Float }

type Query {
  book(id: ID!): Book
  books(filter: BookFilter): [Book!]!
}
  • Scalars are leaves: Int, Float, String, Boolean, ID (plus any scalar you declare, like DateTime).1
  • Object types (Book, Author) are made of fields; a relationship is just a field whose type is another object.
  • ! after a type = non-null — the field is promised never to be null.
  • [T] = a list of T. Nest them: [Book!]! is a non-null list whose items are each non-null.
  • Enum = an allowed set of string values, validated on both sides.
  • Input (input BookFilter) = a type used for arguments, not returned in responses.

Nullability is a promise

Choose ! deliberately. A non-null field that raises means the whole response path up to the nearest nullable field becomes an error. Nullable fields degrade gracefully; non-null fields make the schema honest but strict.1

Key idea The same schema documents the API for humans (Explorer), validates requests, and generates typed clients. Design it before you write resolvers.

Interfaces & unions for polymorphic data

interface Node { id: ID! }
type User implements Node { id: ID! name: String! }
type Review implements Node { id: ID! body: String! }
union SearchResult = Book | Author

type Query {
  node(id: ID!): Node
  search(term: String!): [SearchResult!]!
}

An interface promises a shared set of fields on every implementer; a union lists possible object types with no shared fields. Clients pick concrete members with inline fragments, e.g. ... on Book { title }.1
