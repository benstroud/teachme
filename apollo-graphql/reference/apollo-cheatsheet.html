1. SDL — the schema language

scalar DateTime

enum OrderStatus { CREATED FULFILLED CANCELLED }

type Book {
  id: ID!
  title: String!
  price: Float          # nullable
  tags: [String!]!      # non-null list of non-null strings
  author: Author!       # references another object type
}

type Author {
  id: ID!
  name: String!
  books: [Book!]!
}

input BookFilter { minPrice: Float, published: Boolean }

interface Node { id: ID! }
type User implements Node { id: ID! name: String! }
union SearchResult = Book | Author

# Three root operation types (below). Multiple are allowed:
type Query {
  book(id: ID!): Book
  books(filter: BookFilter): [Book!]!
  search(term: String!): [SearchResult!]!
  node(id: ID!): Node
}

type Mutation { createBook(input: CreateBookInput!): Book }
type Subscription { bookChanged: Book }
  • Scalars: Int Float String Boolean ID. Custom scalars declared with scalar.1
  • ! = non-null; a non-null resolver that throws propagates to the nearest nullable parent.1
  • Arguments use input types (never objects/interface/union).

2. Apollo Server v4 — minimum server

# install
npm i @apollo/server graphql

import { ApolloServer } from '@apollo/server';
import { startStandaloneServer } from '@apollo/server/standalone';

const server = new ApolloServer({ typeDefs, resolvers });
const { url } = await startStandaloneServer(server, {
  context: async ({ req }) => ({
    user: await getUserFromToken(req.headers.authorization),
    db: dbClient,
    loaders: makeLoaders(),
  }),
});
console.log('GraphQL ready at', url);
  • @apollo/server (v4+) replaced apollo-server v3; graphql is a peer dep.2
  • typeDefs = schema (SDL); resolvers = map of type → field → function.
  • The context return value becomes contextValue for every resolver in that request.3

3. Resolvers

const resolvers = {
  Query: {
    book: (_parent, { id }) => db.loadBook(id),
    books: () => db.loadAllBooks(),
  },
  Mutation: {
    createBook: (_parent, { input }, ctx) => db.createBook(input),
  },
  Book: {
    // parent is the object the Query.Mutation resolver returned
    price: (parent) => parent.priceInCents / 100,
  },
  Author: {
    books: (author, _args, ctx) => ctx.loaders.authorBooks.load(author.id),
  },
};

// signature: field(obj, args, contextValue, info)
  • parent = value returned by the parent resolver (documented first arg).4
  • No resolver for a field? Apollo calls the default resolver: reads parent[fieldName].4
  • Nested data = write field resolvers that use the parent; do not fetch the whole graph in one root resolver.

4. Errors & auth

import { GraphQLError } from 'graphql';

// resolver
function mustBeAdmin(ctx) {
  if (ctx.user.role !== 'ADMIN') {
    throw new GraphQLError('Forbidden', { extensions: { code: 'FORBIDDEN' } });
  }
}
// context
context: async ({ req }) => ({
  user: await verify(req.headers.authorization),
})
  • Throw GraphQLError with extensions for structured errors; the client sees them in the errors array.5
  • Authorization lives in resolvers (or a wrapper directive) and reads contextValue.user.6
  • Never put a live password/JWT secret in contextValue; store the verified user.

5. N+1 & DataLoader

import DataLoader from 'dataloader';

async function batchUsers(ids) {
  const rows = await db.loadUsers(ids);          // ONE query
  return ids.map(id => rows.find(r => r.id === id));
}

function makeLoaders() {
  return { users: new DataLoader(batchUsers) };
}
// make a fresh loader per request (contextValue) — never global.
  • load(id) calls within one tick merge into a single batchLoadFn call; results are cached per instance.7
  • Create loaders per request (in context) so cache never leaks across users/requests.
  • The batchLoadFn returns results in the same order as the input keys.

6. Apollo Client (web)

import { ApolloClient, InMemoryCache, gql } from '@apollo/client';
import { ApolloProvider, useQuery } from '@apollo/client';

const client = new ApolloClient({ uri: 'https://api.example/graphql', cache: new InMemoryCache() });
// wrap tree: <ApolloProvider client={client}>...</ApolloProvider>

const BOOK = gql`query Book($id: ID!) { book(id: $id) { id title price } }`;
function BookCard({ id }) {
  const { loading, error, data } = useQuery(BOOK, { variables: { id } });
  if (loading) return <p>loading</p>;
  if (error) return <p>error: {error.message}</p>;
  return data.book.title;
}
  • Wrap with ApolloProvider; run operations with hooks.8
  • InMemoryCache normalizes each object by __typename + id, deduping the same entity across queries.9

7. Federation

# subgraph: @apollo/subgraph
import { buildSubgraphSchema } from '@apollo/subgraph';
const server = new ApolloServer({
  schema: buildSubgraphSchema([{ typeDefs, resolvers }]),
});

# entity: an owning type with a key + reference resolver
type Product @key(fields: "id") {
  id: ID!
  name: String!
  price: Int
}
Product: { __resolveReference(ref) { return db.loadProduct(ref.id); } }

# another subgraph contributes fields and matches on that key
extend type Product @key(fields: "id") {
  id: ID! @external
  reviews: [Review!]!
}
  • Subgraphs compose into a supergraph; Apollo Router serves it and routes queries.10
  • Entities use @key; __resolveReference loads an entity from its key fields alone.11
  • The team that owns a field is the source of truth; other subgraphs extend and mark fields @external.

8. Design checklist

  • Schema first: design the contract in SDL, then write resolvers to satisfy it — never the reverse.
  • Let the default resolver work: return plain domain objects; only write a field resolver when the field needs computation or a nested fetch.
  • Prefer nullable over crashy: put non-null where a field is promised, but remember an exception propagates up to the first nullable boundary.
  • Keep resolvers thin: they coordinate; business logic and DB access live in a service/loader layer behind them.
  • Scope loaders per request and use DataLoader for list-of-nested lookups to beat N+1.
  • Authenticate in context (once per request), authorize in resolvers, raise typed GraphQLErrors with extensions.
  • Design mutation returns as payloads that stay stable as fields grow, not raw scalar echoes that break on change.
  • Federate at the boundary: split a graph by ownership into subgraphs only when teams/lifecycles genuinely diverge.
