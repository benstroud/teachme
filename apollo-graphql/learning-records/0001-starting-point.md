# Starting Point: Apollo GraphQL APIs in TypeScript

The learner is a self-taught TypeScript backend developer working toward senior
JS/TS + Node.js mastery. He understands modern Node, TypeScript typing, and API
design, and has built client-facing backends. His gap is the *GraphQL edge*: how
to own a schema-first, type-safe GraphQL layer end to end with the Apollo
toolset. He wants to master SDL and the resolver model, context and
authorization, data-layer integration (including fixing the N+1 problem with a
DataLoader), client consumption with Apollo Client and its normalized cache, and
scaling a graph across teams with Apollo Federation — and be able to defend the
architecture in a senior interview. This lesson set is designed to be
self-contained and independent of all other courses in the repository.
