The Context Window

A model can only attend to a finite window of tokens at once — which is why prompt length, examples, and retrieved context all compete for space.

The mental model in one sentence

A model attends to a bounded window of tokens — your prompt plus its own output — so what fits in that window is all it can use in a single generation.1

Why there is a limit

Attention lets each token relate to every other, but the weights are built for a fixed maximum length; inputs beyond it cannot be processed at once. This is why models truncate or require you to fit everything relevant inside the window.12

window = context_length            # e.g. a few thousand tokens
used   = prompt_tokens + generated_tokens
# keep used <= window, or earlier content is dropped/truncated

What that means in practice

  • Characters and examples you include consume the window; a long system prompt leaves less room.2
  • Long conversations "forget" the oldest turns as they exceed the window.
  • Retrieval (later lesson) exists partly because you cannot fit a whole knowledge base in the window — you inject only the relevant slice.
Key idea Treat the window as a budget: instructions first, then the most relevant context, then room for the output. When you need more knowledge than fits, you summarize or retrieve rather than paste everything.
