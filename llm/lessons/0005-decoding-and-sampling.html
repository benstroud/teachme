Decoding & Sampling

The model gives probabilities; decoding decides which token to actually emit. Greedy, beam, sampling, and the knobs that shape creativity.

The mental model in one sentence

Language is generated autoregressively — each token is chosen from the model's next-token distribution — and the decoding method (greedy, beam, or sampling, with temperature/top-k/top-p) decides how deterministic or creative the result is.1

The distribution is the raw material

Autoregressive generation assumes the probability of a sequence factorizes into a product of conditional next-token distributions: P(w1..T) = ∏t P(wt | w<t). At each step the model outputs probabilities over the vocabulary; decoding turns that into one token.1

Methods and knobs

Method / knobWhat it does
GreedyPick the argmax (most likely) token each step; fast but can repeat.
Beam searchKeep several candidate sequences; good for constrained tasks.
SamplingDraw from the distribution; more variety, better for open-ended text.
TemperatureLow = sharp/deterministic; high = random/creative.
top-kSample only from the k most likely tokens.
top-p (nucleus)Sample from the smallest set whose cumulative probability > p.
1
Key idea Sampling methods like top-p/top-k usually read as more fluent for open-ended generation, while greedy/beam shine where you want determinism. There is no one right answer — tune to the task.1
