Prompting & Instruction Following

A pretrained model generates continuation; an instruction-tuned model follows your instructions. Prompting is how you steer that.

The mental model in one sentence

The prompt is the full input that conditions the output — instructions, context, and examples (few-shot) — and models that follow instructions are themselves a product of fine-tuning on instruction data.1

The prompt is the whole input

  • Instruction — what you want done ("summarize this").
  • Context — the material the model should work from (fits in the window).
  • Few-shot examples — a couple of input → output pairs that shape the response.1
  • System prompt — top-level behavior/role set by the application.

Instruction following is a capability

Base models were trained to predict text; getting them to reliably follow directions took instruction tuning. The landmark was InstructGPT (2022), a version of GPT-3 trained to follow instructions better, and it opened the era of chat/assistant models.12

Key idea Clarity beats cleverness: state the task, bound the output, and use an example when the format matters. The same fact remains true at the limit — if it's not in the window as instruction or context, it isn't guiding the model unless it was already in its weights.
