Lesson 3 of 10Large Language Models

The Transformer & Attention

The Transformer dropped recurrence entirely and uses only attention — each token looks at every other to gather context.

The mental model in one sentence

The Transformer is an architecture based solely on attention mechanisms — dispensing with recurrence and convolutions — so each position weighs the others to build context, and the whole thing is highly parallelizable.1

What attention does

A word's meaning depends on context — the words around it. Attention lets each token look at every other token and pull context from them, weighted by relevance. Self-attention is attention within the same sequence; multi-head attention runs several of these in parallel so the model can attend to different relationships at once.12

Why it replaced RNNs

Recurrent networks process tokens one at a time in order, which is slow and makes long-range dependence hard. Because attention relates positions directly, the Transformer is more parallelizable and trains significantly faster — while being better on those translation tasks in the original paper.12

Key idea Almost every modern LLM is a decoder-only Transformer: it keeps the attention stack but no separate encoder, and it can only look at tokens it has already generated — enforced by an attention mask that hides future tokens.2
