# Starting Point: Large Language Models

The learner is a self-taught TypeScript developer working toward senior JS/TS +
Node.js mastery. He uses LLM APIs in software but wants a precise mental model of
how these models work and where they fail: tokens and tokenization, the
Transformer's attention, pretraining and scale, autoregressive decoding (greedy,
beam, sampling, temperature, top-k, top-p), context windows, prompting and
instruction following, alignment via SFT/RLHF, grounding answers with
retrieval-augmented generation, and honest evaluation (hallucination, benchmarks,
when to trust a model). This lesson set is designed to be self-contained and
independent of all other courses in the repository.
