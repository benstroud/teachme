Designing Mutation Events

A raw change-stream record is not an event contract. Shape it into a versioned, idempotent, business-meaningful event.

The mental model in one sentence

Turn a database change into an event with a clear source and detail-type, a versioned detail payload, and an idempotency key so consumers can deduplicate.1

EventBridge's event shape

An EventBridge event has source (where it came from), detail-type (what kind), and detail (the payload), plus an id on delivery; rules match on these fields.1

type OrderUpdatedEvent = {
  source: "orders";
  "detail-type": "OrderUpdated";            // verb-like and meaningful
  detail: {
    v: 1;                                   // schema version
    id: "orders:o1:update:5";               // idempotency key
    op: "update";
    orderId: "o1";
    status: "paid";
    at: "2026-09-30T12:00:00Z";
  };
};
Key idea Especially with CDC you are reacting to a state change, not an RPC — so use past-tense, verb-like detail-types (OrderPlaced, OrderUpdated), embed a schema version, and always carry an idempotency key.1
