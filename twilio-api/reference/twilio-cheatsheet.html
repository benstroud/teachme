Twilio Voice Cheat Sheet

The compressed essence of the course. Skim before a lesson, study it fully before an interview.

1. The flow

POST /token  -> Access Token (identity + VoiceGrant)
browser SDK  -> connect(To)
Twilio       -> POST /twiml (must validate signature)
/twiml       -> <Dial callerId=owned to=To>
  • The token authorizes the client; TwiML decides the call.2

2. Accounts & subaccounts

main account
  └─ subaccount (one per org)
       numbers, calls, usage -> billed to main
  • Up to 1,000 subaccounts by default; closing releases numbers; deleted after 30 days.1
  • All subaccount usage bills to one main balance.1

3. Node helper library

const twilio = require("twilio");
const client = twilio(SID, TOKEN); // or API key + secret
// pin twilio@5.5.1; v6 requires Node.js 20
  • API Keys are scopable/rotatable; deleting one revokes its tokens.2
  • v6 has no breaking API changes but needs Node 20.10

4. Access tokens & grants

const { AccessToken, VoiceGrant } = require("twilio").jwt;
const t = new AccessToken(SID, KEY, SECRET, { identity });
t.addGrant(new VoiceGrant({ outgoingApplicationSid }));
const jwt = t.toJwt();
  • Short-lived JWT created server-side; lifetime up to 24h (use shorter).2
  • outgoingApplicationSid names the TwiML app.2

5. Browser Voice SDK

const device = new Twilio.Device(jwt);
device.connect({ params: { To: "+15551234567" } });
  • Use the current v2 SDK, not old 1.x quickstarts.3
  • The SDK is transport; routing lives in TwiML.3

6. TwiML <Dial>

const r = new VoiceResponse();
r.dial({ callerId: FROM }, req.body.To);
res.type("text/xml").send(r.toString());
  • callerId must be an owned or verified number.4
  • The destination comes from the To param on connect.4

7. Webhook security

twilio.validateRequest(
  AUTH_TOKEN, req.headers["x-twilio-signature"],
  EXACT_URL, req.body
);
// JSON: validateRequestWithBody + bodySHA256
  • Use the exact URL (no decode/re-encode); pass sorted form params.5
  • Unvalidated /twiml lets anyone drive your calls.5

8. Phone numbers

// 1) search
client.availablePhoneNumbers("US").local.list({ areaCode: 415 });
// 2) buy + bind
client.incomingPhoneNumbers.create({ phoneNumber, voiceApplicationSid });
  • Search returns candidates; purchase creates ownership.6
  • voiceApplicationSid binds the number to your handler.7

9. Limits & compliance

~1 CPS default (excess queued)  •  concurrent caps  •  4-hour max call
SHAKEN/STIR trusted calling  •  US outbound rules
  • Design retries/UI around CPS, not around 200 OK.8

10. Hardening checklist

validate every webhook  •  dedupe on CallSid  •  queue outbound
transfer numbers before closing a subaccount  •  alert on CallSid + errors
  • Bump the library deliberately; Node 20 before twilio v6.10
