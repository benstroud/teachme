Twilio Glossary

Every term in this course, in one place. Return here when a lesson uses a word you do not fully own.

Accounts & tenancy

main account
The top-level Twilio account that owns subaccounts and pays for their usage.1
subaccount
An account owned by the main account, used to segment a customer's usage and resources.1
AccountSid
The identifier for an account (AC…); it scopes every API resource.
billing roll-up
All subaccount usage bills to the main account's single balance.1
closed subaccount
A subaccount that Twilio deletes 30 days after closure by default.1

Tokens & grants

Access Token
A short-lived JWT created on your server to authenticate a client-side Twilio SDK.2
JWT
A signed, base64url-encoded token with header, payload, and signature parts.2
identity
The user identifier embedded in a token, associating it with a person.2
grant
A permission added to a token (e.g. VoiceGrant) enabling a client capability.2
VoiceGrant
The grant enabling Voice SDK use; it carries an outgoingApplicationSid.2
outgoingApplicationSid
The TwiML app a VoiceGrant points at, so the SDK knows where to ask for instructions.
API Key
A credential used to sign access tokens; deleting it revokes tokens signed with it.2
TTL
Token lifetime; configurable up to 24 hours, but use the shortest feasible.2

Voice flow & TwiML

Voice SDK
The browser/client SDK that connects using an Access Token.3
TwiML
Twilio Markup Language: XML instructions returned to Twilio for a call.
The TwiML verb that connects a call to a number.4
callerId
The number a call appears to come from; must be an owned/verified number.4
TwiML app
An application that points at your webhook URL; numbers and grants reference its SID.

Webhook security

webhook
An HTTP request Twilio makes to your URL when an event happens.
X-Twilio-Signature
The header Twilio uses to sign webhook requests.5
validateRequest
The SDK helper that verifies the signature using the exact URL and form params.5
bodySHA256
The query parameter Twilio appends for JSON bodies; use validateRequestWithBody.5

Phone numbers

AvailablePhoneNumber
A number you can buy, found by searching by area code/pattern.6
IncomingPhoneNumber
A number owned by your account; purchasing/updating it configures voice.7
voiceApplicationSid
The TwiML app a number is bound to, so inbound calls use your handler.7

Limits & compliance

CPS
Calls per second; accounts start at about 1 CPS and queue above it.8
concurrent calls
How many calls can be active at once for an account.8
4-hour cap
A single call can last at most four hours.8
SHAKEN/STIR
Caller-ID authentication (trusted calling) for outbound calls.9

Library

twilio-node
The official Node helper library for the Twilio API.10
version pin
Locking the library version (here 5.5.1) for reproducible installs.
v6 upgrade
The next major, with no breaking API changes but a minimum Node.js of 20.11
