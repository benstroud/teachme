Node.js & TypeScript Glossary

Canonical terminology for backend engineering with Node.js 22 and TypeScript in this workspace.

Runtime & Modules

ESM (ECMAScript Modules)
The standard official module system for JavaScript using import and export statements, natively supported in Node.js.
Avoid: CommonJS, require, module.exports
Type Stripping
The Node.js 22 capability (`--experimental-strip-types`) to execute TypeScript files directly by stripping type annotations at runtime without a separate build compilation step.
Avoid: transpilation, manual tsc build

Types & Contracts

Type Narrowing
The process of refining a broad type (like string | null) to a more specific type using runtime control flow checks (e.g., typeof, if guards).
Avoid: type casting, forced assertion
Discriminated Union
A union type where each member has a common literal property (the discriminant) enabling exhaustive type narrowing in switch or if statements.
Avoid: tagged union, variant record

Backend & I/O

Asynchronous I/O
Non-blocking input/output operations managed via the Node.js event loop using Promises and async/await syntax.
Avoid: callback hell, blocking threads
Runtime Validation
Validating untrusted external input (such as HTTP request bodies) against a schema at execution time while automatically inferring static TypeScript types.
Avoid: loose parsing, manual type casting
