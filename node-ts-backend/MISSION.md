# Mission: Node.js 22 & TypeScript Unified Backend Engineering

## Why
As an experienced programmer, I want to build robust, high-performance backend services using Node.js 22 and TypeScript without the cognitive friction of learning JavaScript and TypeScript as separate paradigms. By unifying syntax, runtime behavior, and static typing from day one, I can immediately design production-grade APIs, handle asynchronous I/O, and leverage Node 22's native TypeScript support.

## Success looks like
- Write and execute native TypeScript backend code on Node.js 22 without manual compilation steps.
- Design type-safe HTTP servers and request/response pipelines using modern ES modules.
- Implement robust runtime validation combined with static type inference using tools like Zod.
- Structure modular, maintainable backend applications with comprehensive testing using Node 22's built-in test runner.

## Constraints
- Target Node.js version 22 runtime environment.
- Combine JavaScript syntax/features and TypeScript types simultaneously in every lesson.
- Keep lessons concise, self-contained, and interactive with practical coding exercises and quizzes.

## Out of scope
- Frontend UI frameworks (React, Vue, etc.) and browser-specific APIs.
- Legacy CommonJS modules (`require`/`module.exports`) except where interoperability is strictly required.
