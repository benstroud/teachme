# Notes & Preferences

- Target audience: Experienced programmer transitioning to Node.js 22 + TypeScript.
- Pedagogical approach: Unified learning (JS syntax + TS typing taught together in every lesson, avoiding separate learning phases).
- Codebase style: ESM (`"type": "module"`), strict TypeScript settings (`strict: true`), clean Tufte-inspired HTML lessons with embedded interactive quizzes and code snippets.
