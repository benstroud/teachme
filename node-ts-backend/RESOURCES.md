# Node.js & TypeScript Backend Resources

## Knowledge

- [Node.js Documentation (v22)](https://nodejs.org/docs/latest-v22.x/api/)
  Official API reference for Node.js 22, including native TypeScript stripping (`--experimental-strip-types`) and built-in test runner. Use for: core runtime APIs, streams, HTTP servers.
- [TypeScript Documentation: Everyday Types & Handbooks](https://www.typescriptlang.org/docs/handbook/2/everyday-types.html)
  Authoritative guide to TypeScript type system. Use for: understanding type narrowing, generics, interfaces, and utility types.
- [Zod Documentation](https://zod.dev/)
  TypeScript-first schema validation with static type inference. Use for: validating runtime HTTP requests and environment variables.

## Wisdom (Communities)

- [r/node](https://reddit.com/r/node)
  Community discussions on Node.js best practices, performance tuning, and ecosystem updates.
- [r/typescript](https://reddit.com/r/typescript)
  Discussions on advanced type-level programming, architectural patterns, and compiler behavior.
