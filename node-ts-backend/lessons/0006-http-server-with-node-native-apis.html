Lesson 6: HTTP Server with Node Native APIs

Mission: Build a zero-dependency typed HTTP server using Node.js 22 built-in modules.

Node.js provides a robust built-in node:http module. By leveraging native HTTP APIs alongside TypeScript interfaces, you can build high-performance backend services without heavy third-party web frameworks.

Zero-Dependency Typed Routing

Consider a modular native HTTP router:

import http, { IncomingMessage, ServerResponse } from "node:http";

type RouteHandler = (req: IncomingMessage, res: ServerResponse) => void;

const routes: Record<string, RouteHandler> = {
  "GET /health": (req, res) => {
    res.writeHead(200, { "Content-Type": "application/json" });
    res.end(JSON.stringify({ status: "ok" }));
  },
  "GET /not-found": (req, res) => {
    res.writeHead(404, { "Content-Type": "application/json" });
    res.end(JSON.stringify({ error: "Not Found" }));
  }
};

const server = http.createServer((req, res) => {
  const key = `${req.method} ${req.url}`;
  const handler = routes[key] || routes["GET /not-found"];
  handler(req, res);
});

server.listen(8080, () => {
  console.log("Server listening on port 8080");
});
Key Takeaway: Node 22 native HTTP modules combined with static dictionaries provide exceptional throughput and zero dependency bloat. Read the Node.js HTTP API Documentation.
