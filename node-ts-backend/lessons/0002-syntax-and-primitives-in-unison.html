Lesson 2: Syntax & Primitives in Unison

Mission: Master modern JavaScript syntax and static typing simultaneously for backend payloads.

In backend engineering, data validation and manipulation form the bulk of business logic. When learning JavaScript and TypeScript together, primitive types and modern syntax features (destructuring, optional chaining, nullish coalescing) operate as a single unified system.

Consult the Glossary for canonical terms like Type Narrowing.

Unified Primitives & Modern Operators

Consider a backend configuration handler parsing environment variables:

interface EnvConfig {
  nodeEnv: "development" | "production" | "test";
  dbUrl: string;
  maxConnections: number;
  apiKey?: string;
}

// Modern JS destructuring combined with TS type annotations
const parseEnv = (raw: Record<string, string | undefined>): EnvConfig => {
  const nodeEnv = (raw.NODE_ENV ?? "development") as EnvConfig["nodeEnv"];
  const dbUrl = raw.DATABASE_URL ?? "postgres://localhost:5432/app";
  const maxConnections = raw.MAX_CONN ? parseInt(raw.MAX_CONN, 10) : 10;
  
  return {
    nodeEnv,
    dbUrl,
    maxConnections,
    apiKey: raw.API_KEY, // Optional property
  };
};

const config = parseEnv(process.env);
console.log(`Connected to database at ${config.dbUrl}`);
