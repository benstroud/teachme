Lesson 7: Generics & Reusable Utilities

Mission: Write reusable, type-safe API wrapper utilities using TypeScript generics.

Generics allow components and functions to work over a variety of types rather than a single one. In backend development, generics are essential for building reusable JSON parsers, caching layers, and repository wrappers.

Generic API Response Wrapper

Consider a generic wrapper for API responses:

interface ApiResponse<T> {
  data: T;
  timestamp: number;
  success: boolean;
}

const wrapResponse = <T>(data: T): ApiResponse<T> => ({
  data,
  timestamp: Date.now(),
  success: true,
});

interface UserProfile {
  username: string;
}

const profileResponse = wrapResponse<UserProfile>({ username: "alice" });
console.log(profileResponse.data.username);
Key Takeaway: Generics preserve precise type information flowing through asynchronous pipelines without resorting to `any`. See the TypeScript Generics Handbook.
