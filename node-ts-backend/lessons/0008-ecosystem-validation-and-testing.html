Lesson 8: Ecosystem, Validation & Testing

Mission: Perform runtime payload validation with Zod and test with Node 22 built-in test runner.

Static typing protects code during development, but backend services ingest untrusted external payloads at runtime. Using Runtime Validation libraries like Zod alongside Node 22's built-in test runner completes your production backend toolkit.

Runtime Validation & Native Testing

Consider validating user registration payloads and testing them with node:test:

import { z } from "zod";
import test from "node:test";
import assert from "node:assert";

// Zod schema definition with automatic static type inference
const UserSchema = z.object({
  username: z.string().min(3),
  age: z.number().int().positive(),
});

type CreateUserDto = z.infer<typeof UserSchema>;

// Native test using Node 22 test runner
test("UserSchema validates correct payloads", () => {
  const input = { username: "bob", age: 30 };
  const parsed = UserSchema.parse(input);
  assert.strictEqual(parsed.username, "bob");
});
Key Takeaway: Combining Zod runtime validation with Node 22's built-in test runner (`node --test`) provides complete test and validation coverage without third-party test runners. See Zod Documentation and Node.js Test Runner Documentation.
