# Starting Point: Rust Programming

The learner is a self-taught TypeScript developer on AWS, working toward
senior-level JS/TS + Node.js mastery. He is deeply comfortable in dynamically
typed, garbage-collected JavaScript and is now learning Rust to add a
statically-typed, zero-cost, memory-safe systems language — and especially the
ownership model — to his mental toolkit. He has a working Rust toolchain
(cargo/rustc 1.84+) installed locally. His gap is Rust's way of thinking: stack
vs heap, ownership/move semantics and borrowing, structs/enums/pattern matching,
Option/Result error handling, the standard collections, and
generics/traits/lifetimes. He wants to read and write idiomatic Rust, fix
ownership and borrow errors by reading compiler messages, and reason about memory
safety — and to defend that understanding in a senior interview. This lesson set
is self-contained and independent of all other courses in the repository.
