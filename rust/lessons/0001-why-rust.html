Why Rust & Getting Started

A systems language that gives you C-level performance with memory safety the compiler guarantees.

The mental model in one sentence

Rust manages memory with a compiler-enforced ownership system — no garbage collector, no manual free — so it's fast and safe at the same time.1

What makes Rust distinctive

  • Memory safety without a GC. Ownership rules run at compile time; the program isn't slowed at runtime by the ownership features.1
  • Zero-cost abstractions. High-level constructs compile down to efficient machine code with no runtime overhead.
  • Fearless safety. The compiler catches whole classes of bugs (use-after-free, data races, null derefs) before the code runs.

For a TypeScript developer, the shift is: JavaScript lets almost anything fly at runtime; Rust refuses to compile code that isn't provably safe — and tells you exactly why.

Your first program with cargo

cargo new hello
cd hello
cargo run

src/main.rs:

fn main() {
    println!("Hello, world!");
}
  • cargo is Rust's build tool + package manager; it scaffolds a project and runs it.2
  • main is the entry point; println! is a macro — the ! marks it.
Key idea Almost everything in Rust is an expression, types are explicit, and the compiler is your safety net. When code won't compile, read the error — it points at the exact rule you tripped over.

Check yourself
