Rust Glossary

Every term in this course, in one place. Return here when a lesson uses a word you do not fully own.

Ownership & memory

Ownership
Rust's memory-management model: a set of compiler-enforced rules, in place of a garbage collector or manual free. Zero runtime cost from the rules themselves.1
Stack / heap
The stack stores fixed-size values in LIFO order (fast, no allocation search). The heap holds values of unknown or variable size, reached through a pointer. String lives on the heap.1
Owner
The single variable that owns a value. When the owner goes out of scope, the value is dropped (memory freed).1
Move
Transferring ownership of a heap value (e.g. a String) to another variable; the original binding becomes invalid. Assignment and function arguments move.2
Copy
A trait for types that copy on assignment instead of moving (integers, bool, float, char).2
Clone
A trait for an explicit deep copy of a value when you need both copies to remain usable.
Reference
A & pointer that borrows a value without owning it; creating one is borrowing.3
Borrowing
Using a value through a reference so the owner keeps it. Governed by the two reference rules.3
Dangling reference
A reference to memory that has already been freed. Rust prevents these at compile time.3
Slice
A borrowed view into a contiguous sequence (&str, &[T]).3

Language & types

immutable / mut
Variables are immutable by default; adding mut lets you reassign the binding.4
Shadowing
Declaring a new let with an existing name, which takes over until its scope ends. Unlike mut, it can change the type.4
Scalar types
Single values: integers (i32, u64, …), floating-point, bool, char.
Struct
A named group of typed fields; instances use Name { field: value }.5
impl
A block that adds methods to a struct (or enum).5
Enum
A type whose value is one of a set of variants, each able to carry data.6
match
An exhaustive control-flow construct that runs an arm per pattern; forces you to handle every case.6
Option<T>
Rust's null-safety enum: Some(T) or None. Distinct from T, so you can't use it as a definite value without handling None.6
Result<T, E>
The type for recoverable errors: Ok(T) or Err(E).7
panic!
A macro that stops execution on an unrecoverable error.7
Generic
A placeholder type (T) so functions/types work across many types; used by Vec<T>, Option<T>, Result<T, E>.8
Trait
A set of shared behaviors — Rust's "interface"; includes Copy, Clone, Debug, Display.8
Lifetime
Information about how references relate so the compiler can keep them valid (annotated 'a).8
