Facets, Synonyms & Production

Polished search mutates with grouped counts (facets), understands equivalent words (synonyms), and holds up under real traffic.

The mental model in one sentence

Facets add grouped breakdowns to results, synonyms make equivalent words match, and production discipline means verifying coverage, relevance, and index health on real data.12

Facets: grouped counts

A facet returns a breakdown of counts by field value or bucket — string facets, numeric/date range facets — so users can filter search results by category, price band, and more. Faceted fields are configured in the index, and the facet collector inside a search stage returns the counts alongside results.1

Synonyms: match equivalent words

You configure synonym mappings in the search index (word sets that should match as equivalents), then queries using those terms also match their synonyms — e.g. "automobile" and "car" find the same products.2

Key idea Facets and synonyms are configured at the index definition, not just in the query. If you want them, design the index for them from the start — you cannot facet on a field that was not indexed as a facetable type.

Production checks

  • Coverage: ensure every field your queries search is actually in the index (getSearchIndexes()).
  • Relevance: project the score, review the top results for a set of real queries, and tune boosts/analyzers.
  • Health: monitor search index build status and size; reindex when mappings change.3
  • Ordering: add a sort so tying scores do not jitter between requests.
