# Starting Point: MongoDB Atlas Search

The learner is a self-taught TypeScript backend developer working toward senior
JS/TS + Node.js mastery. He builds backends on MongoDB Atlas and has implemented
"search" as ordinary `find` filters and regex, which do not produce ranked,
linguistically-aware results or fast prefix/autocomplete behavior. He wants to
master MongoDB Atlas Search (the MongoDB Search engine): the search index
definition (fields, types, analyzers), the `$search` aggregation stage and its
operators (text, phrase, wildcard, regex, autocomplete, range, geo, compound),
reading and tuning relevance scores, and adding facets and synonyms — and to
defend the design in a senior interview. This lesson set is designed to be
self-contained and independent of all other courses in the repository.
