Atlas Search Cheat Sheet

The compressed essence of the course. Skim before a lesson, study it fully before an interview.

1. Mental model

collection  --define index-->  search index (fields + analyzers)
query  --aggregation stage-->  $search (docs) | $searchMeta (metadata)
score  per doc  -->  $project: { score: { $meta: "searchScore" } }
  • You must create a search index on the fields you want to search first.1
  • A search query is an aggregation pipeline beginning with $search or $searchMeta.1
  • Results come back score-descending; a sort gives a determined order.2

2. Define a search index

// dynamic mapping (index all eligible fields)
{ "mappings": { "dynamic": true } }

// explicit field mappings
{
  "mappings": {
    "dynamic": false,
    "fields": {
      "title":  { "type": "string" },
      "body":   { "type": "string" },
      "price":  { "type": "number" },
      "releasedAt": { "type": "date" },
      "location":   { "type": "geo" }
    }
  }
}
  • Index name + collection; choose dynamic vs explicit mappings.3
  • Field types include string, number, date, geo, and the search token type.3

3. Run a search

db.movies.aggregate([
  { "$search": { "text": { "query": "alien", "path": "title" } } },
  { "$project": { "title": 1, "score": { "$meta": "searchScore" } } },
  { "$limit": 10 }
])
  • $search returns matching docs; $searchMeta returns metadata.1
  • Score via $meta: "searchScore"; details via searchScoreDetails.2

5. Compound & scoring

{ "$search": { "compound": {
    "must":    [ { "text": { "query": "red", "path": "color" } } ],
    "should":  [ { "text": { "query": "new",  "path": "tagline", "boost": { "value": 2 } } } ],
    "mustNot": [ { "text": { "query": "used", "path": "condition" } } ],
    "filter":  [ { "range": { "path": "price", "gte": 100 } } ]
}}}
  • must = all required; should = optional but add to score; mustNot / filter = exclude.1
  • Boost amplifies a clause; you can also normalize scores.2

7. Checklist

  • Create the search index before querying; pick dynamic or explicit mappings.1
  • Index the fields you actually search; choose an analyzer that matches your intent.7
  • Use keyword for exact matches, standard for general, n-gram/custom for prefix.
  • Project the score to verify relevance; add a sort for deterministic order.
  • Use compound (must/should/mustNot/filter) instead of chaining logic by hand.
  • Verify with real data and the Atlas UI; recheck index size/coverage in production.
