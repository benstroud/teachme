Atlas Search Glossary

Every term in this course, in one place. Return here when a lesson uses a word you do not fully own.

The basics

MongoDB Search / Atlas Search
The full-text search capability that runs inside MongoDB: index fields, then query them with relevance scoring in an aggregation pipeline.1
search index
A data structure (built per collection) optimized to retrieve documents that meet search criteria; its definition says which fields to index and how to tokenize them.2
$search
The aggregation stage that returns documents matching a search query (as opposed to $searchMeta, which returns metadata).2
$searchMeta
The aggregation stage that returns metadata/analytics about a search (e.g. counts, facets) instead of the documents.2
score
The relevance value assigned to each returned document; results come back highest to lowest. Surfaced with {"score": { "$meta": "searchScore" }}.3
collector
A query component inside a search stage that gathers extra data (e.g. facet counts) alongside matching documents.2

Indexes & analysis

field mapping
How the index definition maps document fields to search fields. Dynamic mapping indexes all eligible fields; explicit mapping declares specific fields and types.4
dynamic vs explicit
Dynamic = inferred mappings for every field; explicit = you define the field -> type mapping yourself.
analyzer
Determines how a string field is tokenized (split into search terms) to control matching.5
Standard / Simple / Whitespace / Keyword / Language
Built-in analyzers: tokenize on word boundaries, non-letters, whitespace, treat the whole string as one term (Keyword, exact match only), or use per-language rules.5
normalizer
Produces a single token (e.g. lowercase, or no transformation); used with the search token type.5
custom analyzer / multi
A custom analyzer you define; multi lets a field be indexed with alternate analyzers too, so you can query with different tokenization.5
token / tokenization
The individual searchable terms an analyzer splits a string into.

Operators & scoring

text / phrase / wildcard / regex
Operators: match analyzed terms (text), an exact sequence (phrase), with wildcards, or a regular expression.2
autocomplete
The operator for prefix / partial-match search suggestions.6
range / geo / nested
Operators matched against indexed number/date ranges, geospatial coordinates, and fields inside embedded documents.2
compound
An operator that combines clauses with must (all), should (any contribute to score), mustNot (exclude), and filter (exclude without scoring).2
boost / normalize
Ways to modify relevance: amplify a clause/term's effect (boost) or rescale scores (normalize).3
facet
A grouped breakdown (counts by string/number/date buckets) returned by the facet collector.7
synonym mapping
A configuration mapping sets of words as equivalent, used by queries to match synonyms.8
mongot
The search process (a dedicated service) that serves search indexes and queries.
