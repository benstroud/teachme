# Odin Resources

## Knowledge

- [Odin Language Overview](https://odin-lang.org/docs/overview/)
  The authoritative introduction to the language, written by the Odin team. Dense but accurate. Use for: any language feature — syntax, types, procedures, control flow, memory.

- [Odin Demo File](https://odin-lang.org/docs/demo/)
  A single comprehensive `.odin` file that demonstrates the full language. Excellent for seeing features in realistic context after learning them in lessons.

- [Official Examples Repository](https://github.com/odin-lang/examples)
  670+ examples including graphics (raylib, OpenGL, SDL2), threading, networking, and memory management. Each is runnable with `odin run .`. Use for: real-world patterns after a concept is introduced.

- [Odin FAQ](https://odin-lang.org/docs/faq/)
  Design rationale and comparisons with C, Go, and Zig. Use for: understanding *why* Odin makes certain choices (no constructors, no exceptions, explicit allocators).

- [Odin Package Documentation](https://pkg.odin-lang.org/)
  Complete API reference for the `core:` standard library and `vendor:` bindings. Use for: anything procedural — fmt, os, strings, math, raylib.

- [raylib Cheatsheet](https://www.raylib.com/cheatsheet/cheatsheet.html)
  All raylib functions in one page. Use for: finding the right drawing/input/audio call quickly once we reach graphics lessons.

## Wisdom (Communities)

- [Odin Discord](https://discord.gg/vafXTdubwr)
  The primary community. Includes the language author (Ginger Bill) and core contributors. Use for: questions that go beyond the docs, design decisions, tricky bugs.

- [r/odinlang](https://reddit.com/r/odinlang)
  Smaller but active. Use for: project showcases, community projects to study.
