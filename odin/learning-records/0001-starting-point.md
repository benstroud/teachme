# Starting point: experienced programmer, zero Odin and graphics

Ben is an experienced, self-taught programmer (productive in TypeScript/JS). He has no prior Odin experience and no prior graphics or games programming experience.

**Implications:** Skip all general programming foundations. The Odin curriculum starts at language-specific syntax and idioms (Lesson 01), then moves quickly to graphics primitives via raylib. Do not re-teach what a function, loop, or variable is — only what is different or surprising about how Odin handles these things.

**Evidence:** Self-described in session opening; consistent with depth of TypeScript work in the adjacent workspace.
