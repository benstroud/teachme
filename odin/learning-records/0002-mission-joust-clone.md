# Mission refined: build a Joust clone

The concrete project goal is a playable Joust clone (1982 Williams Electronics arcade game) using Odin + raylib. This sharpens every future lesson — examples, quiz questions, and mechanics should be grounded in Joust's specific systems: gravity/flap physics, platform collision, screen wrapping, lance-height combat, enemy state machines, wave progression.

**Implications:** When introducing a language feature, illustrate it with a Joust-relevant example (e.g. introduce `for` with a wave-spawn loop, not a generic counter). Lessons 03–04 finish the language foundations; Lesson 05 opens the first window.
