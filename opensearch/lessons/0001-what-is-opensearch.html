What Is OpenSearch

The search-and-analytics engine you already know: documents, indices, shards, and the AWS domain that holds them.

The mental model in one sentence

OpenSearch is an open-source search and analytics engine that stores JSON documents in indices, splits each index across shards, and answers full-text queries at speed; on AWS you consume it as a managed domain (a cluster).1

Elasticsearch and OpenSearch: one search model

OpenSearch began as the open-source fork of Elasticsearch 7.10 (the last fully open-source release), so the two share the same REST model: documents, indices, mappings, analyzers, queries, relevance, aggregations. Amazon OpenSearch Service runs OpenSearch and can also run legacy Elasticsearch OSS versions, so you keep the Elasticsearch API you already know.1

The anatomy of a cluster

PieceWhat it is
Domain (provisioned)AWS's term for a cluster: one set of instances and settings.1
NodeOne server in the cluster; each EC2 instance you choose is a node.1
IndexA named collection of documents with shared fields.
Shard + replicaAn index is split into shards and copied as replicas for scale and failover.
DocumentA single JSON record: the thing you index and search.
Key idea You do not search a single document store — you search an index, which OpenSearch distributes across the cluster's nodes in shards. That distribution is what makes the same REST call work at 10 or 10,000 docs.2
