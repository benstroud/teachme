Full-text Search with Match

Natural-language lookup through the analyzer, and the scored vs unscored match.

The mental model in one sentence

The match query takes natural language, runs it through the field's analyzer, and scores documents that contain any of the resulting terms — full-text search in one call.1

match analyzes the query, too

GET /products/_search
{ "query": { "match": { "name": "copper travel mug" } } }

The terms copper, travel, and mug are each compared against documents; a doc containing all three ranks above one containing only mug.

Query context vs filter context

ContextScore?Typical use
Query contextYes — computes relevance _scoreText you want ranked, like a name search.1
Filter contextNo — match numerically, cacheableBoolean, range, and existence checks (in stock, price range).
Key idea match defaults to operator: "or": any term matches. Set operator: "and" or add minimum_should_match when every term must appear — this is how you tighten recall on a user phrase.1
