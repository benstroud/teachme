# Starting Point: Elasticsearch / AWS OpenSearch

The learner is a self-taught TypeScript backend developer working toward senior
JS/TS + Node.js mastery. He needs to add full-text search and analytics to the
document data his applications store on AWS. He wants to master Elasticsearch as
operated by Amazon OpenSearch Service: the Elasticsearch-compatible REST model —
documents, indices, explicit mappings, `text` vs `keyword` fields, analyzers and
tokenization, `match`/`term` queries, BM25 relevance scoring, and aggregations for
faceted reporting — plus the AWS deployment choices (provisioned domain vs
OpenSearch Serverless) and pagination strategies that matter as search scales.
This lesson set is designed to be self-contained and independent of all other
courses in the repository.
