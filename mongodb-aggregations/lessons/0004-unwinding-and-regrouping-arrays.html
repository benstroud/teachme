Unwind & Regroup Arrays

Turn an array of N into N documents, so you can aggregate over the elements — then group back up.

The mental model in one sentence

$unwind deconstructs an array field: an array of N elements yields N output documents, each with the array field replaced by a single element.1 This "flattens" one document per line-item so you can run $group against the items.

Basic unwinding

// one order with items: [pen, pad, ink]
{ _id: 1, orderId: "o1", region: "EU", items: [
    { sku: "pen", qty: 5 }, { sku: "pad", qty: 2 }, { sku: "ink", qty: 8 } ] }

{ $unwind: "$items" }

// becomes three documents, items now a single element each:
{ _id: 1, orderId: "o1", region: "EU", items: { sku: "pen", qty: 5 } }
{ _id: 1, orderId: "o1", region: "EU", items: { sku: "pad", qty: 2 } }
{ _id: 1, orderId: "o1", region: "EU", items: { sku: "ink", qty: 8 } }
  • The field path is written "$items" — dollar prefix, quoted.1
  • Everything else on the parent document is copied to each output document (here region).

Options: the document form

{ $unwind: {
    path: "$items",
    includeArrayIndex: "position",     // add the 0-based index
    preserveNullAndEmptyArrays: true   // keep docs with null/missing/empty
} }
  • By default $unwind drops a document whose array is missing, null, or empty — use preserveNullAndEmptyArrays: true to keep it and omit the field.1
  • includeArrayIndex records each element's 0-based position in a new field.
  • A non-array, non-null value is passed through as one document.

The flat-then-regroup idiom

Unwind gives you a row per element; now you can aggregate over elements, then bring them back together. Sum revenue per SKU across every order:

db.orders.aggregate([
  { $unwind: "$items" },
  { $group: {
      _id: "$items.sku",
      qtySold: { $sum: "$items.qty" },
      revenue: { $sum: { $multiply: [ "$items.qty", "$items.price" ] } }
  } },
  { $sort: { revenue: -1 } }
])
Key idea Unwind explodes the document count (one order → N rows). Do it only as far as needed, and re-aggregate with $group right after so you don't carry an exploded stream through the whole pipeline.2
