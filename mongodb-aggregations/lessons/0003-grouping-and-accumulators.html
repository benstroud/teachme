$group & Accumulators

Many documents in, one per group out — the heart of aggregation.

The mental model in one sentence

$group collects documents that share a group key and folds each group down to one document using accumulator expressions.1

Anatomy of $group

{ $group: {
    _id: "$region",                    // group key (required)
    orderCount: { $sum: 1 },           // count docs in the group
    revenue:    { $sum: "$total" },    // sum a field
    avgOrder:   { $avg: "$total" },    // average
    cheapest:   { $min: "$price" },    // extremes
    priciest:   { $max: "$price" }
} }
  • _id sets the group key — a field, several fields as a document, or an expression.1
  • Every other output field must be an accumulator: fold the group's values into one.

Group keys and grouping by null

// group by multiple fields: the _id is a nested document
{ $group: { _id: { region: "$region", year: { $year: "$placed" } },
            count: { $sum: 1 } } }

// one aggregate across ALL input
{ $group: { _id: null, grandTotal: { $sum: "$total" } } }

An _id of null (or any constant) puts every document into a single group — the "summary row" of the whole stream.1

The accumulator tool belt

AccumulatorWhat it produces
$sum / $avgTotal and mean of a numeric value.
$min / $maxSmallest / largest value.
$pushCollects values into an array, duplicates kept.
$addToSetCollects unique values into an array.
$first / $lastFirst / last value seen in input order.
$sum: 1The count idiom — one per document.
{ $push: "$$ROOT" }The whole document, collected ($$ROOT = current doc).2
{ $group: {
    _id: "$region",
    skus:  { $push: "$sku" },         // [skuA, skuB, skuA]    — dupes
    tags:  { $addToSet: "$tag" },     // [tagA, tagB]          — unique
    docs:  { $push: "$$ROOT" }        // whole documents
} }
Key idea $group is a blocking stage: it buffers the whole input before emitting. And its output is unordered — sort after grouping, not before.1
