Joining Collections with $lookup

Enrich each document with related documents from another collection — a left outer join in the same database.

The mental model in one sentence

$lookup performs a left outer join to another collection in the same database, adding a new array field whose entries are the matching foreign documents (an empty array when there is no match).1

The equality form

{ $lookup: {
    from: "customers",
    localField: "customerId",     // field on the input documents
    foreignField: "_id",          // field on the "from" docs
    as: "customer"
} }

Each input order gets a customer array — one element when a customer matches, empty when it doesn't:

{ _id: 10, orderId: "o1", customerId: 55 }
→
{ _id: 10, orderId: "o1", customerId: 55,
  customer: [ { _id: 55, email: "ada@x.dev" } ] }

Making it look like a single row

Because $lookup returns an array, the common next move is $unwind to flatten it, and a $match to drop non-matches — emulating an inner join:

db.orders.aggregate([
  { $lookup: { from: "customers", localField: "customerId",
               foreignField: "_id", as: "customer" } },
  { $unwind: "$customer" },        // one order per customer match
  { $match:  { "customer.region": "US" } }
])

The correlated form: let + pipeline

When equality isn't enough (join on a computed or interrogatable condition), use let to bind the current document's fields, then run a pipeline inside $lookup that references them with $$var:

{ $lookup: {
    from: "events",
    let: { oid: "$_id", after: "$someDate" },
    pipeline: [
      { $match: { $expr: { $and: [
          { $eq: [ "$orderId", "$$oid" ] },
          { $gt: [ "$when", "$$after" ] }
      ] } } }
    ],
    as: "postEvents"
} }

The sub-pipeline runs once per input document, so the correlated form is heavier — index the foreign field, or rethink the model.2

Key idea Joins are a signal to reconsider your model. MongoDB prefers embedded related data over joins; use $lookup when data is genuinely separate (customers, users), and keep the joined data out of the 16 MiB result limit (Lesson 9).2
