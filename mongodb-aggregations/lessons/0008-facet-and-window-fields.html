$facet & Windows

Several analyses in one pass, and running totals / rankings over ordered partitions.

The mental model in one sentence

$facet runs several independent sub-pipelines on the same input in a single stage; $setWindowFields computes values across an ordered partition of documents — ranks, running sums, moving windows.

$facet: a dashboard in one query

{ $facet: {
    byRegion:  [ { $group: { _id: "$region", orders: { $sum: 1 } } } ],
    topSellers:[ { $sort: { qty: -1 } }, { $limit: 3 } ],
    totals:    [ { $group: { _id: null, revenue: { $sum: "$total" } } } ]
} }

Output is one document whose keys are the facet names, each holding that sub-pipeline's result array:1

{ byRegion: [ { _id: "EU", orders: 12 }, ... ],
  topSellers: [ { sku: "pad", qty: 300 }, ... ],
  totals: [ { _id: null, revenue: 12490 } ] }
  • All three sub-pipelines see the same input document stream — one scan, many answers.1
  • Perfect for a page that needs counts, top-N, and totals together.

$setWindowFields: partitions, sorts, outputs

{ $setWindowFields: {
    partitionBy: "$region",                 // restart per region
    sortBy: { date: 1 },                    // order within partition
    output: {
      rank:     { $rank: {} },              // 1,2,3… within partition
      rowNum:   { $documentNumber: {} },    // 1-based position in partition
      runTotal: { $sum: "$total",
                  window: { documents: [ "unbounded", "current" ] } }
    }
} }
  • partitionBy splits input into groups; the window math restarts in each.2
  • $rank (with ties) vs $denseRank; $documentNumber is the physical row number.2
  • Accumulators become moving when given a window (a documents/range span). Omit window to use the whole partition.

Running totals and moving averages

// running total per region over time
{ $setWindowFields: {
    partitionBy: "$region",
    sortBy: { date: 1 },
    output: { runningTotal: { $sum: "$total",
                              window: { documents: [ "unbounded", "current" ] } } }
} }

// 3-row moving average of quantity
{ $setWindowFields: {
    partitionBy: "$region",
    sortBy: { date: 1 },
    output: { avg3: { $avg: "$qty",
                      window: { documents: [ -1, 1 ] } } }
} }

Combine with $shift to compare each row to its predecessor (e.g. price change), and time-based range + unit windows for rolling time spans.

Key idea Use $setWindowFields when each row needs its neighbours' influence without collapsing the stream (the way $group would). It is where "trend" and "rank" questions get answered.
