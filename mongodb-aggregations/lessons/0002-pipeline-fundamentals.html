Pipeline Fundamentals

Filter, shape, sort, cap, and count — the stages nearly every pipeline opens and closes with.

The mental model in one sentence

Between the source collection and the final answer, you filter with $match, reshape with $project/$addFields/$set/$unset, order with $sort, and trim with $limit/$skip and report with $count.

Filter: $match is your first move

$match keeps only documents that satisfy a query predicate — the same syntax as find. It deserves to be first: it shrinks the stream before any costly stage and is the one stage the query planner can serve from an index.1

{ $match: { status: "fulfilled", total: { $gte: 100 } } }

Reshape: project, add fields, set, unset

{ $project: { title: 1, region: 1, _id: 0 } }   // keep only these
{ $addFields: { itemCount: { $size: "$items" } } } // add computed field
{ $set:  { reviewed: true } }                      // add or overwrite
{ $unset: [ "secret", "tmp" ] }                    // drop fields
  • $project shapes the output (include/exclude, or just new computed fields). $addFields/$set add and keep everything else.2
  • Keep $project lean — only carry what later stages need. Less data through each stage is cheaper.

Order: $sort, then cap with $limit/$skip

{ $sort: { region: 1, total: -1 } }   // asc by region, desc by total
{ $skip: 20 }                          // drop the first 20
{ $limit: 10 }                         // keep the next 10
  • $sort is a blocking stage: it holds the whole input, then emits in order.3
  • For "top N" always $sort then $limit; $skip/$limit together give paging.

Report: $count and $out

{ $count: "fulfilledOrders" }   // one doc: { fulfilledOrders: N } — must be last
{ $out: "fulfilledSnapshot" }   // write the pipeline output to a collection — last
  • $count returns a single document with the running count; it must be the final stage.
  • $out replaces the target collection; $merge merges into one (both last-stage).4
Key idea Order is a cost decision. Push $match and $limit as early as you safely can, keep $project narrow, and let only the stages that must, block.
