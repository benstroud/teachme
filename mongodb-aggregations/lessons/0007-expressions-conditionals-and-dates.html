Expressions, Conditionals & Dates

Arithmetic, branching, and time math — computing new values inside any stage.

The mental model in one sentence

Expression operators compute a value from fields and constants, are used anywhere a field path can appear, and let you derive numbers, booleans, strings, and dates inside a pipeline.

Arithmetic

{ $add:      [ "$price", 5 ] }
{ $subtract: [ "$total", "$discount" ] }
{ $multiply: [ "$items.qty", "$items.price" ] }
{ $divide:   [ "$total", "$itemsCount" ] }
{ $mod:      [ "$total", 100 ] }

Each is just an array of operands (field paths and constants); the result can feed another operator or an accumulator like $sum.

Conditionals

{ $cond: { if: { $gte: [ "$total", 100 ] }, then: "big", else: "small" } }

{ $ifNull: [ "$nickname", "$fullName", "anon" ] }   // first non-null

{ $switch: {
    branches: [ { case: { $eq: [ "$region", "US" ] }, then: "domestic" },
                { case: { $eq: [ "$region", "CA" ] }, then: "north" } ],
    default: "international"
} }
  • $cond is the ternary; $ifNull collapses missing/null; $switch is the case statement.
  • Use them to classify or normalize fields before grouping.

Dates

{ $dateToString: { format: "%Y-%m", date: "$placed" } }  // "2026-09"
{ $year: "$placed" }  { $month: "$placed" }  { $dayOfMonth: "$placed" }

// shift a date
{ $dateAdd: { startDate: "$placed", unit: "month", amount: 1 } }

// the command's start time (same for all docs)
{ $project: { ageDays: { $divide: [ { $subtract: [ "$$NOW", "$placed" ] },
                                    86400000 ] } } }
  • $$NOW is a fixed moment (the aggregation's start), so it is stable across the pipeline.1
  • Date arithmetic works in milliseconds; divide by 86400000 to get days.

Putting it together

db.orders.aggregate([
  { $addFields: {
      bucket: { $cond: { if: { $gte: [ "$total", 1000 ] },
                         then: "whale", else: "minnow" } },
      month:  { $dateToString: { format: "%Y-%m", date: "$placed" } }
  } },
  { $group: { _id: { bucket: "$bucket", month: "$month" },
              revenue: { $sum: "$total" } } }
])
Key idea Derived and classified fields become clean group keys. Compute them with $addFields, then group on the new fields — a pattern you will reuse constantly.
