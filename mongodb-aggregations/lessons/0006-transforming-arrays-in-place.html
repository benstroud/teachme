Transforming Arrays in Place

Map, filter, slice, and reduce an array without exploding the whole collection — the operators that work inside each document.

The mental model in one sentence

Array expression operators take an array field inside one document and return a new array (or value), so you can reshape nested data per document without unwinding the collection.

$map, $filter, $reduce

// double every price
{ $map: { input: "$prices", as: "p", in: { $multiply: [ "$$p", 2 ] } } }

// keep only items with qty over 5
{ $filter: { input: "$items", as: "i", cond: { $gt: [ "$$i.qty", 5 ] } } }

// total of an array of numbers
{ $reduce: { input: "$nums", initialValue: 0,
             in: { $add: [ "$$value", "$$this" ] } } }
  • Inside these operators, $$this (or your chosen as name) refers to each element; $$value is the running accumulator in $reduce.1
  • $$IDX gives the current element's index while mapping/filtering (8.3+).

Read and slice

{ $arrayElemAt: [ "$tags", 0 ] }    // the first element, as a value
{ $slice: [ "$tags", 2 ] }           // first two elements
{ $size: "$items" }                  // the array's length
{ $in: [ "$sku", "$items" ] }        // true if the value is in the array

Combine and set-operate

{ $concatArrays: [ "$tags", "$extraTags" ] }          // join arrays
{ $setUnion:   [ "$a", "$b" ] }                        // unique of both
{ $setIntersection: [ "$a", "$b" ] }                   // common elements
{ $setDifference:    [ "$a", "$b" ] }                  // in a, not in b

Composing them: a filtered mapped total

db.orders.aggregate([
  { $addFields: {
      bigItemCount: { $size: { $filter: {
          input: "$items", as: "i", cond: { $gt: [ "$$i.qty", 10 ] }
      } } }
  } }
])

Here $filter narrows items, then $size counts the survivors — all inside a single document.

Key idea Prefer in-place array operators when the answer lives inside each document. Reach for $unwind only when you need across-document aggregation over the elements (Lesson 4).
