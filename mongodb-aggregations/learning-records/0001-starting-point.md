# Starting Point: MongoDB Aggregations

The learner is a self-taught TypeScript backend developer on AWS, working toward
senior-level JS/TS + Node.js mastery. He uses MongoDB Atlas as a core data store
and is comfortable with find/insert/update/delete, indexes, and basic queries.
His gap is the aggregation pipeline: turning collections into analytics in the
database instead of loading documents into Node. He wants to master filter,
projection, grouping and accumulators, unwinding arrays, `$lookup` joins,
in-place array transforms, expression algebra over numbers and dates, and the
advanced `$facet` / `$setWindowFields` stages — plus the operational limits
(memory, document size, stage count) and how indexes drive performance — and be
able to defend those designs in a senior interview. This lesson set is
self-contained and independent of all other courses in the repository.
