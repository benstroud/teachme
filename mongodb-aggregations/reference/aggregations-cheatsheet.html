Aggregations Cheat Sheet

The compressed essence of the course. Skim before a lesson, study it fully before an interview.

1. The pipeline mental model

Documents flow through an array of stages; each stage takes documents in and outputs documents, possibly changing their shape. Computation runs in the database; db.collection.aggregate([...]) returns a cursor.1

db.orders.aggregate([
  { $match: { status: "fulfilled" } },   // filter early (uses index)
  { $group: { _id: "$region", total: { $sum: "$total" } } },
  { $sort: { total: -1 } },
  { $limit: 5 }
])

2. Core shaping stages

{ $match: { status: "fulfilled", price: { $gt: 100 } } }
{ $project: { title: 1, region: 1, _id: 0 } }      // include/exclude
{ $addFields: { n: { $size: "$items" } } }          // add computed field
{ $set:   { flag: true } }                          // add/overwrite fields
{ $unset: [ "tmp", "secret" ] }                     // remove fields
{ $sort:  { total: -1, name: 1 } }                  // desc, asc
{ $limit: 10 }
{ $skip:  20 }
{ $count: "total" }                                 // last stage only
{ $out: "copy" }                                    // last stage only
  • $match as early as possible — it is the stage the optimizer/repl can push to an index.4
  • Computed new fields use $addFields/$set; $project shapes.
  • Put $limit after a big $sort (sort, then limit) — or let the optimizer handle it.6

3. Grouping & accumulators

{ $group: {
    _id: { region: "$region", year: { $year: "$placed" } },   // group key
    count: { $sum: 1 },                 // count rows
    total: { $sum: "$total" },          // sum a field
    avg:   { $avg: "$total" },          // average
    minPrice: { $min: "$price" },       // extremes
    maxPrice: { $max: "$price" },
    skus:    { $push: "$sku" },         // collect (allows dupes)
    tags:    { $addToSet: "$tag" },     // collect (unique)
    firstT:  { $first: "$placed" },     // first in input order
    whole:   { $push: "$$ROOT" }        // the whole document
} }
  • _id: null aggregates all input into one document.3
  • $group output is unordered and it is a blocking stage.3
  • The group's output documents must each stay under 16 MiB — watch big $push/$$ROOT arrays.2

4. Unwind & regroup

{ $unwind: "$items" }                      // array of N → N docs
{ $unwind: { path: "$items", preserveNullAndEmptyArrays: true,
             includeArrayIndex: "idx" } }   // options form
  • An array of N elements becomes N documents, the field replaced by one element.7
  • Default drops null/missing/empty-array documents; preserveNullAndEmptyArrays: true keeps them.
  • Common idiom: $unwind → $group back by something in the element.7

5. Join with $lookup

// equality form (left outer join; same database)
{ $lookup: { from: "users", localField: "customerId",
             foreignField: "_id", as: "customer" } }

// correlated form: sub-pipeline matching on the current doc
{ $lookup: { from: "events", let: { oid: "$_id" },
             pipeline: [ { $match: { $expr: { $eq: ["$orderId", "$$oid"] } } } ],
             as: "events" } }
  • Adds an array field; empty array when no match (left outer).8
  • Use $unwind + $match after to emulate an inner join.
  • Correlated form is slower; index the foreign field. Consider embedding instead.

6. Arrays inside a document

{ $map:    { input: "$prices", as: "p", in: { $multiply: ["$$p", 2] } } }
{ $filter: { input: "$items", as: "i", cond: { $gt: ["$$i.qty", 5] } } }
{ $reduce: { input: "$nums", initialValue: 0,
             in: { $add: ["$$value", "$$this"] } } }
{ $slice: [ "$tags", 2 ] }             // first two
{ $arrayElemAt: [ "$tags", 0 ] }       // first element (scalar)
{ $size: "$items" }                    // array length
{ $concatArrays: [ "$a", "$b" ] }      // concatenate arrays
{ $setUnion: [ "$a", "$b" ] }          // unique elements
  • $$this (or $$<as>) references each element; $$IDX its index.12
  • These transform arrays in place — no $unwind of the whole collection needed.

7. Expressions, conditionals & dates

{ $add: [ "$a", "$b" ] }  { $subtract: [ "$a", "$b" ] }
{ $multiply: [ "$a", "$b" ] }  { $divide: [ "$a", "$b" ] }

{ $cond: { if: { $gte: ["$total", 100] }, then: "big", else: "small" } }
{ $ifNull: [ "$nickname", "$fullName", "anon" ] }
{ $switch: { branches: [ { case: { $eq: ["$r", "US"] }, then: "americas" } ],
             default: "other" } }

{ $dateToString: { format: "%Y-%m", date: "$placed" } }
{ $dateAdd: { startDate: "$placed", unit: "month", amount: 1 } }
{ $year: "$placed" }  { $month: "$placed" }
{ $toDate: "$isoString" }

8. Advanced: $facet & windows

{ $facet: {
    byRegion:  [ { $group: { _id: "$region", n: { $sum: 1 } } } ],
    topSellers: [ { $sort: { qty: -1 } }, { $limit: 3 } ],
    totals:    [ { $group: { _id: null, total: { $sum: "$total" } } } ]
} }   // one pass, one document with three arrays

{ $setWindowFields: {
    partitionBy: "$region",
    sortBy: { date: 1 },
    output: {
      rank:   { $rank: {} },                       // 1-based rank
      docNum: { $documentNumber: {} },
      runTot: { $sum: "$total", window: { documents: ["unbounded","current"] } }
    }
} }

9. Limits, memory & speed (design checklist)

  • 16 MiB per result document (BSON). Big $push/$$ROOT/$lookup arrays blow this up.2
  • 100 MB per-stage RAM cap; blocking stages ($group, $sort) may spill to disk when allowDiskUse is on.2
  • 1000 stages maximum in one pipeline.2
  • Filter first: put $match and $limit early to shrink the stream.
  • Index the join foreign key; prefer embedding over $lookup where you can.8
  • Sort then limit for top-N; avoid $sort over huge unindexed sets.
