# Starting Point: AWS CDK in TypeScript

The learner is a self-taught TypeScript backend developer working toward senior
JS/TS + Node.js mastery. He already builds backends on AWS and needs to define and
operate cloud infrastructure as repeatable, reviewable code rather than console
clicks or hand-written templates. He wants to master the AWS CDK in TypeScript:
the App/Stack/Construct model, the L1/L2/L3 construct levels, authoring custom
constructs with props and Tokens, wiring resources with dependencies and IAM
grants, bundling assets, the synth/bootstrap/deploy lifecycle, and context and
Aspects for cross-cutting policy — and to defend the approach in a senior
interview. This lesson set is designed to be self-contained and independent of all
other courses in the repository.
