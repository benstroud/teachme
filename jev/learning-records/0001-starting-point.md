# Starting Point: Jev & TypeSafe System One Models

The learner is a self-taught TypeScript backend developer working toward senior
JS/TS + Node.js mastery. He builds backends where AI/LLM output is increasingly a
factor in program decisions and wants a reliable, typed alternative to coercing
text into JSON. He wants to master Jev, TypeSafe's first System One (decision)
model: the primitives (Choice, Score, Noul), how to write atomic questions and
prepare state, calling it through the Decisions and System One APIs, reading
probabilities and confidence, routing/gating/escalating in control flow, and the
real limits (confidence is not accuracy, validate latency, confirm live pricing)
— and to defend when a decision model versus a generative LLM is the right tool.
This lesson set is designed to be self-contained and independent of all other
courses in the repository.
