The Three Primitives

Choice, Score, and Noul are the question types Jev answers — pick the right one, and read the structured result it returns.

The mental model in one sentence

Jev answers three kinds of typed question — Choice, Score, and Noul — and returns a different structured result for each, all evaluable in parallel in one request.1

The three primitives

PrimitiveQuestion it answersWhat comes back
ChoiceWhich one of these options?the chosen option, a probability per option, and a confidence value
ScoreWhere does this fall on an ordered scale?a probability-weighted position, a probability per level, and confidence
NoulDoes this condition hold / is this statement true?a 0–1 probability
13

Choosing the right one

  • Use Choice when you need one option from a defined set (which team, which model, which category).4
  • Use Score when you need an ordered assessment of severity, priority, or quality on a scale.
  • Use Noul when you need a yes/no — does this condition actually hold?
Key idea The result type drives your code: a Choice branches a router, a Score sets a priority, a Noul guards a gate. Pick the primitive that matches the decision, not the one that feels most AI-like.

Mix and run in parallel

All three question types can be mixed in a single API call. Every question is evaluated in parallel and in isolation against the same state, so adding questions barely increases response time and one question's answer cannot smear another's (no context-rot).1
