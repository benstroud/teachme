What is Jev

TypeSafe's flagship and the first System One model — a frontier-intelligence function call: unstructured state in, typed decisions out.

The mental model in one sentence

Jev is TypeSafe's flagship model and the first System One model: send application state and typed questions, get structured answers your code can use directly — no text generation, no parsing.1

What makes it different

  • Typed outputs, defined in advance. Possible answers and structure are fixed before a request; the model never makes type errors.2
  • It gives up string generation in exchange for structure — which is why, as TypeSafe puts it, it "can't hallucinate": there is no open-ended text to go off the rails.2
  • Calibrated probabilities and confidence accompany every output, so code can judge how much to trust a result.1
  • Built for speed on decisions. A parallel sampler and a training method called RLCD (Reinforcement Learning for Calibrated Decisions) target fast, calibrated system-one judgments.2
Think of Jev as a frontier-intelligence function call: unstructured state in, typed probabilistic decisions out.TypeSafe blog — Introducing System One Models & Jev

Speed and cost, as stated

TypeSafe reports end-to-end responses around 70–500 ms (compared with seconds for frontier LLMs) and claims tens-to-hundreds of times speedups on System One-shaped queries, with input tokens billed and output effectively free. Treat these as positioning you verify, not an SLA.23

Where the names come from

"System One" borrows from Kahneman's fast, intuitive System 1 versus slow, considered System 2. "Jev" is named after the economist William Stanley Jevons, from the idea that each order-of-magnitude drop in the cost of intelligence unlocks far more use cases — like steam-engine efficiency did for coal.2
