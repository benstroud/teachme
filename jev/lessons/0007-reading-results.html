Reading Results

Jev gives you typed values, probabilities, and confidence — read them all, because the probabilities are where the signal lives.

The mental model in one sentence

Each question returns a typed answer plus a probability signal — a Choice returns its chosen option and probabilities per option, a Score a weighted position, a Noul a 0–1 probability — so your code can branch on the value and weigh the certainty.13

What each primitive returns

PrimitiveValueProbability signal
Choicethe selected optiona probability for each option, plus a confidence value
Scorea probability-weighted positiona probability per level, plus a confidence value
Noulyes/noa 0–1 probability of the condition holding

Branch on the typed value

const res = await jev.ask({
  questions: [
    { id: "team",  type: "choice", options: ["billing","support","sales"] },
    { id: "risk",  type: "score",  levels: [1,2,3,4,5] },
    { id: "fraud", type: "noul",   statement: "This request appears fraudulent" },
  ],
});
if (res.fraud.p  > 0.8)           await escalate(res);
if (res.risk.score >= 4)          await queueHigh(res);
routeToTeam(res.team.choice, res.team.probs);

Because the answers are typed, this code is ordinary branching — no parsing, no JSON string-splitting, no accidental schema drift.1

Use the probability signals deliberately

Don't read only the top option. The probability per option and the per-question confidence tell you when to act automatically versus pause for a human — a reliable decision layer treats uncertainty as first-class data.12

Also read usage.cost

Every Jev response includes a usage.cost field in USD, so you can see what a decision actually cost and tune batch sizes and question count against it.3
