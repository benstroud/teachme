Jev & System One Glossary

Every term in this course, in one place. Return here when a lesson uses a word you do not fully own.

The model & the idea

System One model
A new class of frontier model built to make fast, structured decisions that software can use directly — as opposed to generating text for humans. Namesakes: Kahneman's fast/intuitive System 1 versus slow, considered System 2.12
Jev
TypeSafe's flagship model and the first System One model. You send state and typed questions; it returns structured answers (choices, scores, booleans, probabilities) your code can branch on directly. No text generation, no parsing.1
TypeSafe
The company behind Jev, founded by Diogo Almeida (ex-OpenAI). It builds an automation stack around calibrated decision models.2
RLCD
Reinforcement Learning for Calibrated Decisions — TypeSafe's training method, optimizing for answers with epistemically honest probabilities on System One tasks (contrast: RLHF for human preference, RLVR for verifiable outputs).2
state
The context you send with a request: the application state the model judges against (structured program state, often with text). Kept within the model's context window.1
calibrated probabilities / confidence
Every Jev answer ships with probability distributions and a confidence value, meant to be honest about uncertainty so code can decide how much to trust a result.1

The primitives

primitive
One of the three question types Jev answers: Choice, Score, or Noul. Modular and composable like a software primitive.1
Choice
Ask: which one of these options? Returns the selected option, a probability for each option, and a confidence value.3
Score
Ask: where does this fall on an ordered scale (rubric)? Returns a probability-weighted position, a probability per level, and a confidence value.3
Noul
Ask: does this condition hold / is this statement true? Returns a 0–1 probability.13
atomic question
A single, well-scoped judgment — the kind of gut-check a knowledgeable person could make in seconds. Complex judgments should be decomposed into atomic questions and combined in code.1

Calling Jev

OpenRouter
A model hub that routes requests to Jev and bills them to your OpenRouter account; no separate TypeSafe account needed for the Decisions path.3
model identifier
How to name the model on OpenRouter: typesafe/jev-1.13 (with a floating alias ~typesafe/jev-latest).3
Decisions API
An OpenRouter HTTP surface: POST https://openrouter.ai/api/alpha/decisions, for calling Jev from any language.3
System One API
An OpenRouter HTTP surface: POST https://openrouter.ai/api/v1/systemone, for pointing the official TypeSafe SDK at OpenRouter via a base-URL change.3
context window
Jev's input limit — 32,000 tokens (state plus questions) as documented on OpenRouter.3
