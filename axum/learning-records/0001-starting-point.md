# Starting Point: Axum 0.8 HTTP APIs

The learner is a self-taught TypeScript and Node.js developer working through the Rust set. He has rustc 1.84.1 and no recorded experience with Axum or Tower. Lessons 4 and 7 depend on the Rust set's `Result`, `?`, and trait material, so he should be comfortable with those before reaching them. The lab crate in `code/` pins dependency versions that build on 1.84.1, so no toolchain update is needed to run the examples. This set is independent of other courses except for references to the Rust and Tauri sets.
