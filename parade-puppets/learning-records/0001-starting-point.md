# Starting point: complete beginner with backpack puppet ambitions

The user has no prior puppet-making or advanced crafting experience. They are interested in backpack-style parade puppets specifically — the kind worn on the back with the puppet towering above the puppeteer. Their initial motivation is personal creative hobby, with ambitions to eventually participate in community parades and events. No time pressure. Budget and tool access assumed to be modest/home-workshop level.

## Implications

- Start with structural literacy before any hands-on building. The user needs to understand the anatomy of a backpack puppet before trying to build one.
- Avoid assuming familiarity with crafting tools (staple pliers, PVC cutters, etc.) or techniques (papier-mache, lashing).
- First build project should be simple and forgiving — prioritize getting a complete puppet done over making a beautiful one.
