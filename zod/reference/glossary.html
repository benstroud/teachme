Glossary

Terms as this set uses them. Each entry names the lessons where it appears, and the lab file that runs it.

Core

Schema
A value built with Zod's functions, such as z.object, that checks data at run time and derives a type. Lessons 1, 2.
parse
The method that returns the checked value, or throws a ZodError when the input is invalid. Lesson 2. Lab: user.ts.
safeParse
The method that returns an object with success, and data or error, without throwing. Lesson 2. Lab: user.ts.
z.infer
The TypeScript type of a schema's output, derived from the schema. Lessons 1, 2, 6.
ZodError
The error thrown by parse, and held by a failed safeParse. Its issues array lists each problem. Lesson 4.
Issue
One problem found by a check, with a code, a path, and a message. Lesson 4.
Path
The array that locates an issue, such as ["favoriteNumbers", 1]. Object keys are strings and array indices are numbers. Lesson 4. Lab: errors.ts.

Shapes and choices

Strip
The default for z.object: unknown keys are removed from the result. Lesson 3. Lab: objects.ts.
z.strictObject
An object schema that rejects unknown keys. Lesson 3, Lesson 10.
z.looseObject
An object schema that keeps unknown keys in the result. Lesson 3, Lesson 10.
optional
Allows the value to be undefined. Lesson 3.
nullable
Allows the value to be null. The key must still be present. Lesson 3.
default
Fills in a value when the input is undefined. Lesson 3.
Discriminated union
A union whose branches share a key with a literal value, which picks the branch. Lesson 5. Lab: unions.ts.

Transforming and checking

transform
A function that runs after a schema accepts the value, and returns the value the program uses. Lesson 6. Lab: transforms.ts.
Input and output types
The type that goes into a schema, from z.input, and the type that comes out, from z.output. They can differ after a transform. Lesson 6.
refine
A check added to a schema, which returns true or false. The path option says which field it belongs to. Lesson 7. Lab: refine.ts.
superRefine
A check that receives a context and may add several issues through ctx.addIssue. Lesson 7.
z.coerce
A schema that converts the input with a constructor such as Number, then checks it. Lesson 8. Lab: coerce.ts.
z.preprocess
A function that changes the input before the rest of the schema runs. Used here to turn an empty string into undefined. Lesson 8.

Using it at the edges

Boundary
The point where data enters the program, such as a request body or a config file. Parse here, and pass the typed result inward. Lesson 9.
JSON Schema
A standard description of a JSON shape, which z.toJSONSchema produces from a Zod schema. Lesson 9.
z.treeifyError
Reshapes an error to match a nested schema. Lesson 4. Lab: errors.ts.
z.flattenError
Reshapes an error into formErrors and fieldErrors, one level deep. Lesson 4.
