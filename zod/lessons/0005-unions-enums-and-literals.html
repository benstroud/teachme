Unions, Enums, and Literals

Real data has choices: a value is one of several shapes, or one of a fixed set of words. Zod models these with unions, enums, and literals, and a discriminated union picks its branch by one key.

Fixed values

z.literal accepts exactly one value. z.enum accepts one of a list of strings. Use an enum where the set of allowed words is fixed and the code needs to check each one.1

const Status = z.enum(["open", "closed"]);
type Status = z.infer<typeof Status>;   // "open" | "closed"

const Kind = z.literal("circle");

Plain unions

z.union tries each option in order, and the first that validates is returned.1 It is simple, but it gives a poor error when every branch fails, since the issue list must cover all options.

const Id = z.union([z.string(), z.number()]);
Id.parse(5);    // 5
Id.parse("a");  // "a"

Discriminated unions

When each branch has a key that says which one it is, use z.discriminatedUnion. Zod reads the key first and checks only the matching branch, so the errors describe the right shape.1

const Shape = z.discriminatedUnion("kind", [
  z.object({ kind: z.literal("circle"), radius: z.number().positive() }),
  z.object({ kind: z.literal("square"), side: z.number().positive() }),
]);

Shape.parse({ kind: "circle", radius: 2 });   // ok
Shape.safeParse({ kind: "triangle" }).success; // false
Model the variants as data A discriminated union turns "which kind of thing is this" into a checked key. That gives you a narrowed TypeScript type in each branch, which connects to the narrowing lesson in the TypeScript set.

Check yourself

What does z.union do with its options?

A plain union checks options in order and returns the first success. Choosing by a key is the job of a discriminated union.1

What does a discriminated union use to choose a branch?

Each branch declares the shared key with a literal, and Zod uses its value to pick the branch.1

Which schema allows exactly the words "open" and "closed"?

A string enum takes an array of allowed words. A plain string accepts any text, and literal takes one value, not a list.
